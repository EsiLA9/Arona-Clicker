# 羁绊卡片 → 已完结剧情 = 正常重开（goto 语义，分支自由探索）

## 设计裁定（按你的分析落定）

上游 Story 允许 PassiveStoryEntry 式重复抽取，本身就宣告「该事件可多次经历、可分支探索」。因此羁绊卡片的语义定为：**「进入/再次进入这段剧情」= goto 重开**，与未完结路径的 `startCardStory` 完全同构（清游标 + 跳过入口判定），对已完结剧情补一个 `force` 绕过 AlreadyCompleted 即可。不再走 `replayStory` 的「重看」框架（isReplay=true 的受限回放，branchGuards 生效、无任何记录）——那是留给**故事栏重读**（mode 'replay'）的语义。

## 玩法情况分析（方案如何覆盖）

| 情况 | 处理 |
| --- | --- |
| 分支探索：重开时选另一分支 | choice 效果覆写同一 flag（如 `bond_hoshino_choice: committee↔forget`），下游读该 flag 的内容看到最新选择；数据设计上接受「最新选择生效」或改用追加型 flag |
| 宿主被动剧情被 goto 丢弃 | 随机闲聊可再抽；台阶/尾巴丢弃后未完结 → 留在就绪队列，下次进入对话空间 / clickSend idle 重新推送，内容不丢只是延后 |
| 奖励重复发放 | 重复完结走 `applyCompletionReward` 的 repeat 评估（一般不配置 → 无效果、无 `storyRewarded` 事件、无奖励行）；storyLog 追加一条（可统计经历次数）；`storyCompleted` 再发——依赖它的 Trigger 再次触发，与「再次经历」语义一致 |
| branchGuards | 仅在 isReplay（故事栏重读）时生效；卡片重开 = 自由探索，不受守卫限制 |
| 开幕横幅 | 每次进入（含重开）都随 `beginStory` 呼出，仪式一致 |
| `.replayable()` 字段 | 卡片路径不再依赖；保留在 bond 条目上（未来故事栏挂载时供重读入口用） |

## 实现

### 1. 引擎：卡片入口 = goto 重开
`src/engine/game/story-service.ts` `startCardStory`（L193-196）：
```ts
startCardStory(storyId: string, owner?: string | null): StoryStartResult {
  this.runtime.cursorFor(owner).clear();
  // 卡片入口 = goto 重开：跳过入口判定；已完成剧情亦可正常重新开始
  //（isReplay=false 分支自由探索；奖励走 repeat 评估一般不发放）。
  return this.startStory(storyId, 'active', owner, { skipConditions: true, force: true });
}
```
`force` 在 clear 之后仅剩「跳过 AlreadyCompleted」一个作用，对未完结路径零行为变化。

### 2. UI：确认分支收敛
`src/ui/controller-actions-story.ts` confirm：`mode 'card'` **一律** `startCardStory`（删除 `hasCompletedStory → replayStory` 分支）；mode 'replay' 仍走 `replayStory`。

### 3. 浮层文案
`src/ui/components/story-gate.ts`：`confirmText` 改三态——mode 'replay' → 「重新观看」；已完成 → 「**重新开始**」；否则「进入」。

### 4. 测试
- **引擎**（chat-flow-service.test）：已完结 bond 剧情再 `startCardStory` → 成功落第 0 页；二周目选另一 choice → flag 被改写（分支探索）；storyLog 增至 2 条；重复完结不产生 `storyRewarded`（repeat 未配置）。
- **UI 集成**（story-gate.test）：游标被占用（Hoshino 沙盒先播台阶剧情）→ 卡片浮层确认 → 羁绊剧情照常重开（死锁解除的核心回归）；完结卡片浮层文案为「重新开始」。
- **组件**：完结剧情 confirm 文案断言改「重新开始」。

### 5. 文档
- `planning.md` §3「已完结重看」bullet 改写为重开语义（goto、分支自由、repeat 奖励评估、宿主丢弃回队列）。
- `ui.md` storyGate bullet 同步（确认分支收敛 + 文案三态）。

## 不做 / 边界
- `replayStory` / 故事栏重读（isReplay、branchGuards）语义不动。
- 不改 `completeStory` 的 storyLog 追加行为（重复完结留多条记录，供统计与 `hasCompletedStory.some` 语义）。
- 横幅时长维持你手改的 3 秒（单一常量 `BANNER_ANIMATION_MS` 已收敛）。
