# 核心玩法循环

## 循环总览

```
                       ┌──────────────────────────┐
                       │    离线/挂机阶段          │
                       │  Spot 自动产出资源        │
                       │  (每 tick 生产一次)       │
                       └──────────┬───────────────┘
                                  │ 资源积累
                                  ▼
                       ┌──────────────────────────┐
                       │    资源分配阶段           │
                       │  购买/升级 Spot           │
                       │  解锁/升级 Enhancement    │
                       │  解锁新 Area              │
                       │  解锁/购买角色            │
                       └──────────┬───────────────┘
                                  │ 满足条件
                                  ▼
                       ┌──────────────────────────┐
                       │    剧情互动阶段           │
                       │  ActiveStory（主线推进）   │
                       │  PassiveStory（聊天触发）  │
                       │  获得剧情奖励             │
                       └──────────┬───────────────┘
                                  │ 奖励回馈
                                  ▼
                       ┌──────────────────────────┐
                       │    效率增长阶段           │
                       │  角色提供全局加成          │
                       │  Enhancement 提供倍率      │
                       │  Spot 产出速率提升         │
                       └──────────┬───────────────┘
                                  │ 加速挂机循环
                                  ▼
                         (回到挂机阶段，循环加速)
```

## 双轨产出体系

### 资源轨道——直接产出

| 产出方式      | 产出物            | 速率影响因素                          | 离线支持   |
| --------- | -------------- | ------------------------------- | ------ |
| Spot 自动生产 | 各类资源（金、晶石、食品等） | Spot 等级 × Enhancement 加成 × 角色加成 | 是，离线收益 |

### 剧情轨道——间接提升

| 方式 | 触发方式 | 奖励类型 | 离线支持 |
|------|----------|----------|----------|
| ActiveStory（主线） | 进入 Area 或满足条件时解锁 | 资源奖励、新 Spot、新 Enhancement、角色解锁 | 否，需主动推进 |
| PassiveStory（聊天） | 点击聊天按钮随机抽取 | 资源奖励、小量加成 | 否，需主动点击 |

两种产出**不绑定**：即使完全不推进剧情，挂机收益照常增长。剧情层是"增值层"而非"必要层"。

## 放置/挂机阶段

### 挂机产出

- **产出物**: 每个 Spot 按定义产出特定资源（ResourceAmount）
- **产出速率**: 每 tick（≈1 秒）产生一次，数值 = 基础产出 × (1 + 所有倍率加成之和)
- **离线收益**: 离线时长 × 离线时产出速率 × 0.5（折半作为离线补偿），上限 8 小时

### 自动化行为

- Spot 自动生产无需玩家操作
- Enhancement 效果被动生效
- 角色加成自动计算

## 主动游玩阶段

### 玩家操作清单

| 操作                | 频率      | 说明                     |
| ----------------- | ------- | ---------------------- |
| 点击聊天按钮            | 零散触发    | 随机抽取 PassiveStory，获得奖励 |
| 购买 Spot           | 低频（分钟级） | 消耗资源购买新 Spot，提升产出      |
| 升级 Spot           | 低频（分钟级） | 消耗资源提升 Spot 等级，指数增长的价格 |
| 购买/切换 Enhancement | 低频      | 全局或区域性的加成              |
| 在 Area 间移动        | 低频      | 探索新区域，触发新的 ActiveStory |
| 推进 ActiveStory    | 中频      | 触发条件后进入剧情阅读模式          |
| 切换 Init（世界线）      | 极低频（周级） | 解锁新 Init 后切换，开始新的游玩周期  |

### 战斗系统

本游戏**不包含传统战斗系统**。剧情中的冲突通过对话选项和条件判断解决，不涉及数值对抗或操作对抗。角色不参与"战斗"，其价值体现在提供资源产出加成的被动能力上。

### 剧情系统

- **触发方式**: 
  - ActiveStory: 进入特定 Area、持有特定 Spot/Enhancement、满足 Tag/资源条件时解锁
  - PassiveStory: 在 Area 中点击聊天按钮时，按权重从可用的 PassiveStory 池中随机抽取
- **推进方式**: 线性（Talklet 序列），允许简单的多选分支
- **演出形式**: 纯文本对话 + 角色名称标识（无立绘/动画的初期版本）
- **故事回顾**: 已完成的故事可在菜单中重新查看

## 奖励结构

| 奖励类型 | 获取途径 | 频率 | 用途 |
|----------|----------|------|------|
| 基础资源 | Spot 自动产出 | 持续 | 购买/升级 Spot、Enhancement、解锁 Area |
| 剧情资源奖励 | ActiveStory / PassiveStory 完成 | 每次剧情触发 | 同上 |
| 新 Spot/Enhancement | 满足条件后解锁/购买 | 低频 | 扩展产出/加成体系 |
| 角色 | 特定剧情/条件解锁 | 极低频 | 提供全局加成，提高挂机效率 |
| 新 Init 解锁 | 当前 Init 完成主要目标 | 周级 | 开始新的世界线探索 |

## 循环衔接

**挂机 → 剧情**: 挂机积累的资源用于解锁 Spot/Enhancement，这些会触发新的剧情条件

**剧情 → 挂机**: 剧情奖励注入资源，完成剧情解锁的角色/Enhancement 直接提升挂机效率

**Init 切换**: 当当前世界线的主要剧情完成后，玩家可解锁下一个 Init。切换时携带部分资源/角色进入新世界线，但 Spot 和 Enhancement 重置，形成新一轮"从零起步"的放置体验。
