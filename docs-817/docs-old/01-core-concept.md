# 游戏核心概念

## 一句话描述

在什亭之匣中探索不同的基沃托斯世界线，通过放置经营积累资源，在聊天与剧情中邂逅学生，体验轻松而温暖的平行物语。

## 核心幻想

玩家扮演"老师"，在阿罗娜（Arona）陪伴下，通过什亭之匣进入不同的世界线。每个世界线都是一个迷你箱庭——在区域间移动、建造生产设施、积累资源、解锁强化，同时通过聊天和剧情与学生建立联系。这是一个不需要肝、不需要强度焦虑的"副游"，核心满足感来自"看着箱庭慢慢运转"和"偶尔点开和学生的小故事"。

## 游戏类型

- **放置/挂机权重**: 高 — 核心资源循环全自动运行，离线持续产出
- **RPG 权重**: 低 — 没有传统战斗数值对抗，剧情是主要驱动力
- **其他元素**: 剧情演出 / 轻度收集 / 箱庭经营 / 世界线探索

## 目标平台

Web（桌面端 + 移动端浏览器），TS + HTML 纯前端，无需后端服务器。

## 竞品参考

| 游戏 | 相似之处 | 差异化 |
|------|----------|--------|
| Cookie Clicker | 核心放置循环（建筑 + 升级） | 有剧情、有世界线探索、有角色收集 |
| Nekopara / 视觉小说 | 角色互动与剧情驱动 | 加入放置经营循环，有策略性资源分配 |
| 蔚蓝档案（原作） | 世界观、角色、剧情风格 | 不包含 Gacha 抽卡、PVP、总力战等重度系统 |

## 目标用户

- Blue Archive 粉丝，想体验更轻松、无压力的同人作品
- 喜欢放置类游戏（Cookie Clicker 类）的玩家
- 愿意每天花 10-15 分钟收菜、看剧情的轻度玩家
- 不需要实时在线、不追求排名的"佛系"玩家

## 克制原则（引擎层面）

本游戏采用数据包（Datapack）驱动的内容架构，但引擎本身保持轻量：

- 数据包 = 遵循约定格式的 JSON / TypeScript 模块，**不是**需要独立解析器的专有格式
- 引擎提供注册表（Registry）存取值定义，不实现重量级加载管线
- 不实现模组热加载、版本兼容性适配、补丁合并等企业级功能
- 所有数据在游戏初始化时一次性加载完成
