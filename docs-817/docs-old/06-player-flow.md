# 玩家游玩流程

## 首次进入流程

```
打开页面 → 初始化数据包 → 进入默认 Init（SCHALE）
       → 自动播放起始剧情（阿罗娜打招呼）
       → 显示当前 Area 及默认 Spot
       → 资源开始自动产出
       → 提示"点击聊天按钮试试？"
       → 首次点击聊天 → 触发第一条 PassiveStory
       → 获得首次剧情奖励
       → 提示"收集足够资源后，试试购买新 Spot"
       → 首次购买 Spot → 看到产出提升 → 循环开始
```

## 日常游玩流程

```
登录
  → 弹出离线收益摘要（获得的资源总量）
  → 进入游戏，查看当前资源持有量
  → （可选）收集/清理累积的 Spot 产出（自动入账）
  → （可选）购买/升级 Spot，提升产出
  → （可选）购买/切换 Enhancement
  → （可选）点击聊天触发 PassiveStory
  → （可选）在 Area 间移动，触发新剧情
  → （可选）推进 ActiveStory 主线
  → （可选）检查是否有新的 Init 可解锁
  → 关闭页面/切换标签（游戏自动在后台继续 tick）
```

单次日常时长：5-15 分钟。核心是"想做什么就做什么"，不设每日必做清单。

## 各阶段体验目标

| 阶段 | 时长 | 核心体验 | 解锁内容 |
|------|------|----------|----------|
| 新手期 | 首次会话（30min） | 认识阿罗娜，了解游戏机制 | 基础 Spot、首个 PassiveStory |
| 探索期 | 第 1-3 天 | 购买 Spot，体验产出增长，触发初始 ActiveStory | 多个 Area、Enhancement 系统 |
| 成长期 | 第 4-7 天 | Area 探索，角色解锁，主线剧情推进 | Character 系统、Area 解锁 |
| 深入期 | 第 1-4 周 | 深度养成 Spot/Enhancement，收集角色，完成主线 | 全部系统 |
| Init 循环 | 主线完成后 | 切换 Init，开始新一轮世界线探索 | 新 Init 内容 |

## 剧情体验流程

```
ActiveStory:
  满足解锁条件 → 入口出现在左栏/中栏
  → 玩家点击进入 → 顺序演出 Talklet
  → 遇到分支选项 → 玩家做出选择
  → 剧情继续到结束 → 发放奖励
  → 剧情标记为已完成

PassiveStory（聊天）:
  玩家在 Area 中点击聊天按钮
  → 引擎按权重从当前 Area 的可用 PassiveStory 池中抽取
  → 顺序演出 Talklet（通常较短）
  → 发放奖励
  → 回到游戏界面
  → 同一故事可重复触发（每次奖励较小）
```

## 重大时刻

| 时刻 | 触发条件 | 体验 |
|------|----------|------|
| 首次进入游戏 | 打开页面 | 阿罗娜引导教程，获得初始 Spot |
| 首个角色解锁 | 完成特定剧情条件 | 获得角色加成，感受到收集驱动力 |
| 首个 Area 解锁 | 资源积累达到条件 | 新区域、新 Spot、新故事，内容扩展 |
| 首个 Init 完成 | 完成 Init 的主要剧情目标 | 解锁新 Init 选择，体验世界线切换 |
| Init 切换 | 解锁后手动选择 | 重置非持久内容，携带角色进入新世界线 |

## Init 切换流程

```
当前 Init 主线完成 → 新 Init 解锁提示出现
  → 玩家在 Init 选择界面查看各 Init 信息
  → 选择目标 Init
  → 确认切换（提示将重置 Spot/Enhancement/非持久资源）
  → 进入新 Init
  → 自动播放起始剧情
  → 开始新一轮游戏（保留角色和持久资源）
```

## 无压力设计

- **无体力限制**：不做以时间为计量单位的功能上限
- **无每日次数**：聊天/剧情/购买均无每日使用次数限制
- **无强制进度**：玩家可以永远停留在同一个 Init 中，保持所有进度
- **可回溯**：已解锁的 Init 可随时切回，不损失进度
- **死亡不存在**：没有任何惩罚机制或损失机制
