# 全局整体流程

记录时间：2026-06-24

## 核心循环

```
游戏启动 → Init 选择界面 → 选择 Init → 开场故事 → 箱庭探索与剧情展演 → 抵达出口 → 重新选择 Init
```

## Init 选择界面

- Init 有解锁需求，玩家可以查看到**已被探索到**的 Init
- 允许进入被允许探索的 Init 进行一次新的游戏
- 不可用的 Init 不显示或显示为锁定状态

## 进入 Init

- 玩家选择 Init 后，首先进入**开场故事**（ActiveStoryEntry 演出）
- 开场故事承担引导和世界观引入的功能
- 开场故事结束后，进入箱庭的自由探索阶段

## 自由探索阶段（核心玩法）

进入 Init 后，玩家在多个 Area 之间自由移动，通过以下行为推进游戏：

### 资源系统

- 资源类型**完全由数据包自定义**，引擎不预设任何资源类型
- 资源获取途径多样：Talk 奖励、Spot 自动产出、ActiveStory 奖励、Enhancement 效果、探索度奖励等

### 核心交互

#### Talk 按钮（核心循环入口）
- 有点击冷却/间隔（CD），CD 期间按钮不可用或显示倒计时
- 点击 → 检查 CD → CD 冷却中则等待 → CD 就绪则执行：
  1. 抽取 PassiveStory
  2. 抽中 → 进入故事演出，故事结束后通过 ContextBehavior 获得资源奖励
  3. 未抽中 → 获得保底基础收益（少量资源）
- CD 结束后可再次点击

#### Spot（产出设备）
- 在当前 Area 的 Spot 列表中可见
- 点击卡片进行购买（首次）或升级（已有）
- Spot 提供持续自动产出，是资源的主要稳定来源

#### Enhancement（强化）
- 获得一次性特殊效果/强化
- 获取途径多样：
  - 挂靠在多种实体下（如 Area、Spot、ActiveStory）
  - 通过其他手段赠送（故事奖励、ContextBehavior 等）
- 购买后永久生效（在当前 Init 内或全局）
- 没有独立商店页面，在各自所属的实体界面中展示和购买

#### ActiveStory（剧情推进）
- 在左侧菜单中有一个**故事列表页**，按 Area 分组展示可用的 ActiveStory
- 满足条件后玩家可以点击进入该 ActiveStory
- 进行主线/支线剧情，推动故事发展
- 演出期间，Talk 按钮行为切换为推进当前故事

#### Area 移动
- Area 有连通性约束，不是所有 Area 之间都能直接移动
- 引入 **Map 概念**：Map 是 Area 的分组，在同一个 Map 内的**已探索 Area** 作为一个集合，玩家可以在集合内快速移动
- 未探索/未解锁的 Area 需要先满足条件才能加入快速移动集合

### 玩家目标

- 探索各类数据实体（Area、Spot、PassiveStory、ActiveStory 等）
- 推进 ActiveStory 以推进剧情
- 最终完成整个 Init 的故事线

## Init 出口

- 通常会有 Enhancement 或 Spot 指定了"离开"的能力
- 当某个特定 Spot 或 Enhancement 被获得后，提供退出当前 Init 的功能
- 玩家使用该出口离开当前 Init，回到 Init 选择界面
- 出口条件和方式由数据编辑者定义

## 跨 Init 继承

- 资源是否跨 Init 保留，由**资源自身的定义**决定（`persistent` 标记）
- `persistent = true` 的资源始终保留，用于全局经济
- `persistent = false` 的资源在退出 Init 时根据 Init 的继承策略重置
- Enhancement 的继承由 Init 定义中的 `inheritEnhancements` 决定
- 全局 Enhancement（`scope = "global"`）不受 Init 切换影响

## 游戏节奏

- Tick（游戏刻）对玩家**隐藏**，玩家不直接感知 tick 的存在
- Spot 自动产出在后台运行
- **支持离线收益**：离线期间 tick 继续推进，Spot 持续产出，玩家上线时一次性结算

## 存档

- **自动 + 手动**双模式存档
- 自动存档：定时或在关键节点（如 Init 切换、重要故事完成）自动保存
- 手动存档：玩家可随时手动保存

## 终局

- 没有最终结局
- 玩家完成一个 Init 后，可反复重玩已完成的 Init（**无限 NG+ 循环**）
- 全局 Enhancement 和 persistent 资源跨周目累积，提供持续成长感

## 界面布局

```
┌─────────────────────────────────────────────────────────┐
│  [顶部栏] 资源展示（可选的，玩家可自定义显示哪些资源）       │
├──────────┬──────────────────────────┬────────────────────┤
│ [左侧]   │ [中间] 聊天框            │ [右侧]             │
│ 功能菜单  │                          │ 当前 Area 的       │
│          │  故事演出 /               │ Spot 框            │
│ - Area   │  Talk 按钮               │                    │
│   列表   │                          │ Spot1  [购买/升级] │
│ - 故事   │  聊天历史                 │ Spot2  [购买/升级] │
│   列表   │                          │ Spot3  [锁定]      │
│ - 设置等  │                         │                    │
└──────────┴──────────────────────────┴────────────────────┘
```

## Init 的特性

- Init 是一个**相对封闭的游戏箱庭**
- 所有 Init 实质上共享一个类似的世界观和角色组，存在隐含的各类关系
- 玩家在单个 Init 内需要完成数据编辑者对该 Init 的剧情展演
- 直到获得编辑者提供的出口手段，才能重新选择 Init
