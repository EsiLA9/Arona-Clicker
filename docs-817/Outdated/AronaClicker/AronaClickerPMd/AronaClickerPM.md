# 游戏GameFlow
## PlayTrack
游戏的核心内容:
- 探索不同的世界线，完成世界线的主线剧情
	- 重点是收藏？*游戏本体不太支持世界线重载，玩家应该完成所有的游戏内容* 
- 探索不同世界线的
- 使用青辉石抽取学生与其他物品

# 计划书
## Init
Init是游戏选择世界线后固定的开局。
每次游戏开始时，可以选择已经获得的Init，即开局故事。
不同的开局故事将会有不同的起始剧情、起始所有物、起始地点乃至资源等。（initFunclet & initTalk）
而不同的开局也会导致整个世界拥有不同地点、不同的建筑与升级，和可能进行的剧情。
同时，每个开局故事拥有它们的独特标识符：
###### 倾斜率
即神圣之塔的对地倾斜率。它是一个较长的数字符串，首部数字表示：

| 首字符 | 含义              |
| --- | --------------- |
| 9   | 近似原始版本的故事。      |
| 7-8 | 主题化的原始版本故事。     |
| 4-6 | 改变了部分内容的主线剧情重写。 |
| 1-3 | 发生了重大变故的世界线。    |
| 0   | 原始世界线故事。        |


## Area 
地点是游戏探索的最小单位。玩家在地点上:
- 发起 PassiveTalk
- 查看与购买 Spot, Upgrade

Area 允许通过互联的方式移动。

同时，玩家也可以通过其他方法探索得到Area。

## Spot 
Spot 类似其他 CookieClicker 游戏的建筑物。玩家在持有 Spot 后可以:
- 获得持续的产出。
- 允许进行资源的转换。
###### 限制
Spot 可能有获得上限的限制。

## Upgrade 
Upgrade 是在获得 Area, Spot 等等之后允许购买/获得的项目。
玩家在持有 Upgrade 后可以:
- 获得倍数性的产出。

## PassiveTalk 
PassiveTalk 由简单的点击完成，展现角色或者地区的小小剧情。
通常 PassiveTalk 不会影响非常大的状态。*需要写死这一点吗？* 

PassiveTalk需要凑齐Tag后才能在序列里触发。
在触发后给予一定奖励。（首次奖励与多次触发奖励？）
对PassiveTalk的可能归因:
###### 重要
- InArea 是否处于Area
- HaveItems 是否有某物件
- ReachMilestone 里程碑记录
- CustomTag

## ActiveTalk 
ActiveTalk 是需要主动发起的连续剧情。
ActiveTalk将会写明要求。

## EndOfGame
游戏允许进行终局，从而开始新的 Init。
