# 概述
`TagTemplate` 用于定义一组可被统一归类、统计与引用的模板集合。
它可以指向任意一种模板类型，但通常不用于指向 `ResourceValue`、`PassiveStory` 与 `ActiveStory`。

## targetType
该 `Tag` 所指向的目标模板类型。
一个 `Tag` 只负责归类同一种类型的模板，例如一组 `Area`、一组 `Spot`、一组 `Story`，或一组 `Enhancement`。

## memberTemplateList
该 `Tag` 当前包含的具体模板列表。
在系统允许的前提下，玩家可以自行决定这个 `Tag` 最终会指向哪些具体模板。

## 统计用途
`Tag` 负责承接游戏内与模板交互相关的聚合统计。
例如，玩家通过该 `Tag` 归类的模板总计获得了多少次、激活了多少次，或由这类模板总计产出了多少内容，都可以在 `Tag` 维度上进行记录与查阅。

## 条件与 Trigger
`Tag` 也是条件系统与 `Trigger` 常用的信息源之一。
当需要判断玩家是否拥有某一类模板、累计接触过多少相关内容，或某一类模板是否达成特定统计要求时，可以直接查阅对应的 `Tag`。

## Affector 目标
`Tag` 可以作为 `Affector` 的目标方存在。
这使系统能够对某一整类模板统一施加影响，例如提升某个 `Tag` 下模板的产出、降低其消耗，或改变其相关行为。

## 其他常用元素
###### InitialName/Description
初始名称与描述，后续可能因效果、状态或其他原因发生变化。

###### AffectorBundles
作用于该 `Tag` 的效果集。
