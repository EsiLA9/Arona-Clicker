# 概述
`InitTemplate` 用于定义一条世界线箱庭的起点。玩家会在该 `Init` 下，以相对独立的货币体系与持有物展开探索。

## ?StartStory
进入该 `Init` 时默认触发的 `Story`。

## defaultArea
该 `Init` 的默认返回 `Area`，用于在拓扑异常或目标区域缺失时提供兜底入口。
该 `Area` 也会默认赠送给玩家。

## defaultEnhancementList
默认挂靠在该 `Init` 上的 `Enhancement` 列表。
这类 `Enhancement` 会在类似重生、重新选择 `Init` 以开始新一轮故事的环节中，作为可选内容参与选择。

## Worldline Value
用于展示的世界线数值信息，取值范围通常为 `0-1.0000000...`。

## 其他常用元素
###### defaultPriceBundle
解锁该 `InitTemplate` 所需的价格。

###### InitialName/Description
初始名称与描述，后续可能因效果、状态或其他原因发生变化。

###### AffectorBundles
作用于该 `Init` 的效果集。
