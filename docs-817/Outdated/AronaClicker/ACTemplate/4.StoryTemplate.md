# 概述
`StoryTemplate` 用于定义由多个 `Talklet` 组成的完整演出内容。
其中，`Talklet` 是最小的演出单元；`Story` 本身只负责存储 `Talklet` 表，并按线性顺序完成整段剧情。

## Talklet
`Talklet` 是故事演出的最小单位。
一次对话、一段旁白、一个分支选择，或一次小型表现片段，都可以作为一个 `Talklet` 存在。

## talkletList
该 `Story` 所包含的 `Talklet` 列表。
故事通常按列表顺序依次演出，直到线性完成整个流程。

## completeRewardBundle
完成该 `Story` 后发放的奖励内容。
奖励可以是资源、解锁项，或其他由系统支持的收益。

## 其他常用元素
###### InitialName/Description
初始名称与描述，后续可能因效果、状态或其他原因发生变化。

###### AffectorBundles
作用于该 `Story` 的效果集。
