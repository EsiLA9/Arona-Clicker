# 概述
`Spot` 从属于 `Area`，表示区域内具有鲜明特征的地点或构件。
它类似经典放置类游戏中的生产设施，在获得后可持续产出资源，并通过后续升级提升产出能力。

## parentArea
每个 `Spot` 只能隶属于一个 `Area`。

## ?startStory
获得该 `Spot` 时默认触发的 `Story`。

## defaultEnhancementList
默认附带的 `Enhancement` 列表，通常较少使用。

## 其他常用元素
###### defaultPriceBundle
直接购买该 `Spot` 所需的价格。

###### produceValueByPurchaseList
首次获得该 `Spot` 时提供的基础产出能力。

###### defaultUpgradePriceBundle
对该 `Spot` 进行升级时使用的起始价格组。

###### upgradeExponentValueConfig
`Spot` 的升级价格按指数增长。
该配置决定每一级升级在 `PriceBundle` 基础上的增长系数。
购买后初始等级为 `0`。

###### produceValueByUpgradeList
每一级或每 `N` 级升级提供的固定资源产出增量。

###### InitialName/Description
初始名称与描述，后续可能因效果、状态或其他原因发生变化。

###### AffectorBundles
作用于该 `Spot` 的效果集。
