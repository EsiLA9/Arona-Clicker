# 概述
`EnhancementTemplate` 用于定义可附加到其他模板上的强化内容。
它通常用于补充数值、附加效果，或改变目标对象的表现方式。

## 适用对象
`Enhancement` 可以挂靠在 `Init`、`Area` 与 `Spot` 上，作为这些模板的附加内容存在。
它既可以通过各模板的 `defaultEnhancementList` 提供，也可以由其他系统按需授予。

## 挂靠在 Init 上
挂靠在 `Init` 上的 `Enhancement` 主要用于影响一轮流程的起始状态。
在类似重生、重新选择 `Init` 并再次开始故事的环节中，这类 `Enhancement` 应允许被选中。

## 其他常用元素
###### defaultPriceBundle
获得该 `EnhancementTemplate` 所需的价格。

###### InitialName/Description
初始名称与描述，后续可能因效果、状态或其他原因发生变化。

###### AffectorBundles
作用于该 `Enhancement` 的效果集。
