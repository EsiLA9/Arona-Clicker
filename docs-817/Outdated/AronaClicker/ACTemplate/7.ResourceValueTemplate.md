# 概述
`ResourceValueTemplate` 用于定义游戏中的资源。
它负责表述某一种资源的基础信息，以及该资源在系统中的显示与结算含义。

## 资源用途
`ResourceValue` 可以用于价格、奖励、产出与消耗等场景。
`PriceBundle`、`produceValueByPurchaseList`、`produceValueByUpgradeList` 与 `completeRewardBundle` 等内容，都可以基于 `ResourceValue` 进行表达。

## 其他常用元素
###### InitialName/Description
初始名称与描述，后续可能因效果、状态或其他原因发生变化。

###### AffectorBundles
作用于该资源定义的效果集。
