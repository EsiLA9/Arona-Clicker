## 分区定位

| 相邻分区 | 分工 |
| --- | --- |
| `06-adr/` | 设计权威：背景 / 裁定 / 后果 / 实现记录 |

- 状态推进**只改本区**（目标篇的里程碑表 + 进度记录）；设计变更回对应 ADR，本文区不重复设计内容；
- 目标完成或废弃后标注归档状态，不删除。
