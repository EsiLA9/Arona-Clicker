# roadmap-0013 — 自定义表现控件编辑器体验重构

> 本文规划表现目标编辑器的局部刷新、目标与图层合并展示，以及颜色/图片图层的变换参数编辑。目标注册与宿主数据结构继续以 `roadmap-0012` 和当前源码为准。

## 目标

使全局背景、面板、按钮、Tab、卡片和气泡等表现目标都使用一致且可操作的编辑器，同时避免用户每次修改图层时看到整个主题 Modal 大幅重建。

每个表现目标拥有独立的图层数据；不同目标只共享编辑器能力，不共享图层内容。

## 当前问题

1. 图层增删、类型切换和排序会重新渲染整个 `user-theme-modal`，造成滚动位置、展开状态和视觉焦点跳动。
2. `user-theme-target-summary-row` 与 `user-theme-layer-collapsible` 分离，用户无法把“目标本身”和“目标的图层”作为一个编辑单元操作。
3. 宿主图层虽然已有部分通用字段，但纯色/渐变仍使用文本输入，图片缺少完整的变换参数。
4. 删除目标与删除目标内某一图层的语义没有区分。

## 设计原则

- 目标是编辑器的一级单元；目标头部与其图层列表必须处于同一个可折叠容器内。
- 目标删除只删除用户对该目标的配置，目标本身回退到系统颜色层、父级或全局默认表现，不删除内置目标注册表内容。
- 图层编辑器采用统一字段协议，不再为背景、面板、按钮分别维护一套表单。
- 类型切换后只显示该表现类型需要的参数；无关参数不参与渲染解析。
- UI 事件只更新 draft，并通过定向刷新更新对应目标或图层；保存仍由 `UserThemeService` 统一处理。
- 浅色/深色模式仍由既有主题接口控制，本任务不新增深色模式算法。

## 目标编辑单元

```text
表现目标卡片
├─ 目标标题：名称、级别、父级、继承状态
├─ 删除目标：移除该目标的用户配置
├─ 折叠目标：隐藏全部图层，仅保留标题
├─ 图层 1：统一图层编辑器
├─ 图层 2：统一图层编辑器
└─ 插入新图层
```

全局背景仍额外显示不可删除的系统颜色层；其他目标不复制系统颜色层。删除全局背景的用户图层不会删除系统颜色层。

## 图层表现类型

### 空

- 不产生视觉内容；透明度、变换和内容参数隐藏。
- 切换为其他类型时生成对应安全默认值。

### 纯色

- 使用原生色彩编辑器（`input[type=color]`），不经过 Color 系统语义节点。
- 支持透明度、缩放和旋转角度。
- 颜色值仍由图层自身保存，不能反向修改主题 Token。

### 渐变

- 使用渐变编辑器而不是普通文本框。
- 初版支持两个颜色停靠点，每个停靠点使用原生色彩编辑器。
- 支持渐变透明度、缩放和角度。
- 内部仍输出受控 CSS `linear-gradient`，禁止开放任意 CSS 字符串注入。

### 图片资源

- 通过 Navi/资源选择器选择 Pic 引用。
- 支持透明度、缩放、位置和旋转角度。
- 继续支持尺寸、重复、附着和混合模式。
- 资源只保存稳定 Pic ID，不保存临时 URL。

## 数据与解析计划

### E0：参数契约

- 为 `BackgroundLayerDef` 增加或整理受控变换字段：透明度、缩放、角度、位置。
- 确认渐变停靠点的最小数据结构，并保留对现有渐变字符串的读取兼容路径；新编辑结果使用结构化值。
- 统一背景宿主与控件宿主的默认值、边界和安全过滤。
- 同步引擎类型、schema 和相关测试。

### E1：统一图层渲染模型

- 将颜色、渐变和图片的编辑值转换为统一的只读解析结果。
- 在 TypeScript 侧完成数值夹取、角度归一化、缩放范围限制和 CSS 安全生成。
- 确保空图层不会产生 DOM 视觉层或错误样式。

### E2：目标卡片重构

- 将目标摘要行与目标图层编辑器合并为一个 `user-theme-target-card`。
- 目标标题提供名称、级别、父级/继承状态、折叠按钮和删除按钮。
- 删除目标时移除对应 `presentation.hosts` 项；全局背景只清空用户背景层。
- 保留目标平级列表，不恢复区域嵌套编辑模式。

### E3：局部刷新

- 拆分主题编辑器渲染入口：颜色区、目标列表、单个目标卡片、单个图层卡片分别可更新。
- 普通输入事件只更新当前字段和预览，不重建整个 Modal。
- 插入、删除、排序和类型切换只刷新当前目标卡片。
- 目标新增后仅插入新的目标卡片，并自动展开/聚焦，不影响其他目标的折叠状态和滚动位置。
- 目标 Modal 选择器继续使用全局居中 Modal，不嵌入底部小区域。

### E4：颜色与图片控件

- 为纯色增加原生色彩选择器。
- 为渐变增加双色停靠点、透明度、缩放和角度控件。
- 为图片增加资源 Navi、透明度、缩放、位置和角度控件。
- 统一控件中文标签、键盘操作、禁用状态和实时预览反馈。

### E5：清理与验证

- 清理宿主编辑器中与全局背景重复的旧渲染函数和事件绑定。
- 验证目标删除后的父级/全局回退。
- 验证刷新不会重置滚动、折叠、焦点和输入中的值。
- 验证多个目标的图层互不串写。
- 在 Edge 中检查全局背景、左栏、按钮和图片图层的编辑体验。

## 非目标

- 本任务不改变主题色列表、语义节点和颜色继承算法。
- 本任务不开放任意 CSS 属性或任意 CSS 函数字符串。
- 本任务不实现深色模式算法。
- 本任务不建立旧存档迁移逻辑。
- 本任务不让不同表现目标共享同一份图层数组。

## 验收标准

- 修改单个图层不会导致整个 `user-theme-modal` 大幅闪烁或重建。
- 目标标题、目标删除、目标折叠和目标图层在同一个目标卡片内。
- 删除目标后，该目标回退到系统颜色层/父级/默认表现。
- 任意宿主目标都能使用同一套图层操作：插入、折叠、删除、排序和类型切换。
- 纯色、渐变和图片均可通过专用控件编辑，不依赖 Color 系统节点。
- 纯色/渐变支持透明度、缩放、角度；图片额外支持位置调整。
- 目标新增、图层类型切换和排序后，其他目标的状态保持不变。
- `npx tsc --noEmit`、专项测试和 Edge 视觉验证通过。
