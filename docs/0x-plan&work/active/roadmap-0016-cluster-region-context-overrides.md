# Roadmap-0016 — 簇与区域状态表现关系收束

> 将“左侧栏·区域”等目标定义为左侧栏切换到对应 Tab 时的整套上下文表现，而不是簇内部的第二个可见背景容器。

## 目标

统一颜色作用域与表现层的簇—区域关系：簇提供基础默认值，当前 Tab 对应的区域状态在同一物理宿主上覆盖簇；区域未设置的项目继续继承簇，避免两套背景同时渲染导致簇级表现主导。

## 核心规则

- `left` / `leftPanel` 是左侧栏基础簇；`left.area` / `leftPanel.area` 是区域 Tab 状态。
- 区域状态是上下文覆盖，不是 DOM 内嵌背景：最终只渲染一套左侧栏背景图层。
- 颜色节点按 `root → 簇 → 当前区域` 继承；区域同名节点优先，空值回退簇。
- 表现层按宿主合并；当前区域有定义时覆盖对应簇属性，未定义属性继承簇。
- 系统颜色层在最终宿主图层栈中只出现一次，并遵守最终宿主的忽略与排序设置。
- 未激活的区域状态不参与当前画面；切换 Tab 时重新选择有效上下文。

## 暂不处理

- 不改变主题色列表、明暗模式和文字可读性算法。
- 不新增存档迁移；现有开发期数据结构可直接调整。
- 不把不同 Tab 的状态同时绘制到同一栏位。

## 完成标准

- 左侧栏仅存在一套最终背景图层。
- 当前区域有定义的颜色/表现属性覆盖左侧栏簇默认值。
- 当前区域无定义时视觉结果与仅配置簇时一致。
- 切换 Tab 不产生重复系统颜色层或父子背景叠加。
