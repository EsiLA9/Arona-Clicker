# G03：Runtime Editor 一次完成成就创作

## 对最终目标的贡献

数据包作者用一张创作表单填写目标归属、引入与完成条件、前置成就、效果及展示文案；编辑器在内部维护隐藏 Milestone、Listener 和可见 Achievement 的关系。

## 完成定义

- [ ] 单一 Runtime Editor 流程可创建、编辑和删除三层关联内容，不要求作者手动维护三套 ID 与引用。
- [ ] 草稿保存、回读、热提交与数据包导出无损；已有定义不能完整回写时给出问题并阻止静默覆盖。
- [ ] 作者能看见可执行 Effect 与条件唤醒能力限制；无效引用与不受支持的配置可定位，导出包能重现手写样例的玩家体验。

## 依赖与边界

- 前置 Goal：G01 的可玩链路和 G02 的完整声明契约。
- 本阶段暂缓：独立数据包编辑器、成就自身奖励和领取、图标分类、隐藏规则及 Roadmap。

## 会改变方案的未知项

- 本地源码待核对：Runtime Editor 的 Authoring Policy、热提交、草稿持久化及导出边界；三层定义合成和无损回读方案。
