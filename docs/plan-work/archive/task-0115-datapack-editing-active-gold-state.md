# Task：数据包编辑态入口的金色活动反馈

状态：done — 2026-09-19 实现、自动化核验与浏览器视觉验收完成，待归档

## 来源与问题

数据包 Pane 已经使用“普通态 / 编辑态”按钮完成状态选择与编辑器进入，但进入某个 Mod 的编辑工作区后，按钮仍只表现为普通选中态。用户无法从数据包列表快速确认当前正在编辑哪一个 Mod。

## 目标

1. 当某个编辑态被二次点击并实际打开对应 Mod 的编辑面板时，将该 Pane 的“编辑态”按钮显示为金色活动态。
2. 金色活动态必须按 `packRecordId` 精确对应当前 Runtime Editor 目标，不能因为同一 Pane 的普通态、当前查看态或其他编辑态被误触发。
3. 首次选择编辑态、启用集草案待 Apply、编辑面板关闭或只存在 Debug 预加载编辑态时，不显示“正在编辑”的金色活动态。
4. 不改变 Pane Selection、启用集 Apply、编辑态持久化和编辑器入口行为。

## 交互契约

```text
编辑态按钮
  ├─ 首次点击：只选择编辑态，不显示编辑中金色态
  ├─ 再次点击：进入该 packRecordId 的编辑面板，按钮显示金色
  └─ 关闭编辑面板：移除编辑中金色态，但保留普通的选择/查看语义
```

金色只代表“当前编辑面板正在编辑该编辑态数据包”，不代表 Runtime 来源、启用集状态或数据包详情查看状态。
