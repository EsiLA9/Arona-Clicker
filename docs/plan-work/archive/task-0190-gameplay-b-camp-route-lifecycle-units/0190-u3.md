# Patch Unit 0190-U3：Camp sCost 生命周期

## Goal

在 U2 Route Runtime 与 Battle Preparation 上增加一次性 camp modifier 生命周期。节点 6 的 `initialSCostBonus` 只用于下一场战斗开场；Node 10 的 `rechargeBonus` 保留 `fromRound`，从目标战斗指定回合起生效，战斗结束后不影响后续战斗。

## Confirmed Facts

- 当前战斗 sCost 只在该战斗内持续；胜利、失败、平局终态清零。后续战斗从基值 2 重建，不读取前战余额。
- Node 6 开场 +1 只在下一战第 1 轮生效；Node 10 的 `rechargeBonus.amount` 从 `fromRound` 开始追加在普通回复之上，遵守 cap 5。
- 活战结算中，只有存活且本轮 Observe 的成员获得结算后 +1；此值会成为下一轮输入。案例 7 中无牌角色的 Node 10 round-2 start 为 `2 + 1 Observe + 1 普通回复 + 1 camp 回复 = 5`，攻击并付费的角色依实际余额计算。
- camp modifier 与 Route roster/当前战斗 sCost 分开保存，并只消费于最近的下一场战斗。

## Constraints

- `model.ts` 的 modifier/view 类型来自 U2；仅在本 Unit 白名单内实现 `prepareBattleRound` 的 modifier 计算及 Route Runtime 的登记/消费。
- 初始 +1 只在 round 1 应用；回复加成仅当存活且 `round >= fromRound` 应用；各项 cap 为 5。
- 多个待应用 camp 输入不得静默丢失；不同 `fromRound` 冲突应显式拒绝或在实现前修订契约，不猜合并语义。
- 同时验证目标 Boss 战之后的新战斗不继承 camp modifier，及失败/平局战斗终态 sCost 为 0。
- 不升级 R06/R09/R10 暂定状态，不修改 `model.ts`、内容/UI、包配置或 AC。

## Completion Criteria

- Node 6 opening bonus只在紧随其后的下一战 round 1 生效一次；后续新战回到 base sCost。
- Node 10 fixture 在活动前加入 Reina，固定治疗全队（含倒地成员），不消费活动骰；指定 Boss 战 round 2 的回复额外 +1，遵守 cap 5，Boss 后的新战不继承。
- victory/defeat/draw 均不把前战 sCost 带入下一战；路线战斗视图在 defeat/draw 显示终态余额清零。
- Observe 结算恢复、普通回复与 camp 回复分别验证；Round 1 不提前应用 Node 10 modifier。
