## 一、统一空间坐标与固定无限轴测参考平面

### 坐标来源与兼容

- 保留现有二维坐标与求解器，将求解结果 x/y 和节点 `elevation ?? 0` 组合为逻辑空间点 `(x, y, z)`。缺省 z 为 0，现有二维节点无需逐一修改。
- 当前 elevation 就是逻辑 z 的唯一高度来源；不同时维护 z 与 elevation 两份可写值。若局部命名统一为 z，须在同一个坐标适配入口兼容旧 elevation，不能在各渲染函数分别决定优先级。
- 坐标解析、空间投影、参考平面 / 网格、节点本体、平面投影点及边端点共享一组函数和参数。投影返回绘制点，不改写原布局缓存或业务数据。
- 使用 viewBox 中心作为稳定参考原点，节点坐标相对该原点投影；轴测参数保持稳定，不根据当前节点范围或每次选择、揭示、取得自动拟合。
- 节点比例缩放 x/y 平面方向的节点、网格、真实航道与脚点；所有几何围绕当前图 viewBox 中心缩放，不改变参考原点。z 高度按平面倍率变化量的 25% 缩放：`1 + 0.25 × (scale - 1)`，使 100% 精确为 1:1，10% 为 77.5%，1000% 为 325%。画布滚轮在光标位置锚定缩放，滑杆从 10% 到 1000%；母图初版曾只响应子图比例尺变化量的 15%，最新裁定改为同倍率缩放。切换图 / 布局断点仍可使用各自 viewBox 的中心参考系。
- 节点视觉尺寸在低于 100% 时另按非线性倍率缩小；到达 40% 及以下只画单圆点、短字形与投影点，不显示图标、徽标和长标签。Frontier 仍只显示问号，不泄露名称。

### 投影合同

可采用以下轴测公式；参数集中定义，不要求逐字照抄函数名：

```text
screenX = centerX + scaleX * (x - y)
screenY = centerY + scaleY * (x + y) - heightScale * z

nodePoint  = project(x, y, z)
planePoint = project(x, y, 0)
```

- `scaleX`、`scaleY`、`heightScale` 为正；z 只影响竖直投影分量。固定 x/y、改变 z 时，节点连续竖向移动，planePoint 保持不变；不要求新增高度编辑器或动画。
- 平面表示 z=0，并延伸到视口之外；绘制少量低对比网格与刻度，越过画布边缘时裁切。不得绘制有限边界或随节点范围变化的矩形 / 多边形。
- 网格与节点采用同一轴测参考参数，不叠加会二次扭曲坐标的整张 SVG CSS rotate / skew。
- 当前图每次只显示一块参考平面。母子图各有自己的逻辑范围与投影参数；进入另一图时切换到该图的平面。
- 平面原点固定在逻辑 viewBox 中心，不因节点范围或 z 改变；比例尺围绕该原点缩放网格与平面坐标，相机平移则移动共享观察层。随机新增节点仍按原规则使布局缓存失效，新节点继续相对同一参考系呈现。

## 二、节点本体、脚点与高度辅助线

- 实际节点始终位于 nodePoint，是唯一主要点击、选择与焦点对象；名称、图符、状态与选中标记跟随该位置，保持正立可读，不随平面变成扁平文字。
- z≠0 时，在 planePoint 绘制小点或空心环，并画连接 planePoint 与 nodePoint 的细虚线。节点本体明显强于脚点，辅助线比航道更细、更淡。
- 正高度的辅助标记可偏青，负高度可偏紫；这些只是高度提示，不替代 Frontier / Known / Owned 的状态表达。不必改变节点主体的已有状态色。
- z=0 时不画多余高度线 / 独立脚点，避免所有节点都带重复圆环；已有零高度节点依然可用。
- 隐藏节点不生成本体、脚点、辅助线或标签；未知节点仍是问号及通用名称，不因图符泄露真实内容。几何高度可以展示，不赋予新解锁语义。
- 辅助图形不响应鼠标、不参与 Tab；点击脚点或高度线不能当成点击实际节点。装饰层不得扩大节点命中区域或挡住相邻节点。

## 三、空间航道、平面投影与层级

| 图形 | 端点 | 表现与语义 |
| --- | --- | --- |
| 空间航道（必做） | 两端节点的 nodePoint | 相对明确，表示现有真实边 |
| 高度辅助线（必做） | 同节点 planePoint → nodePoint | 细、淡、虚线，仅解释高度 |
| 平面航道投影（可选） | 两端节点的 planePoint | 极淡细虚线，不成为新边 |
| 共通入口曲线（必做） | 母图概览入口 → 子图实际入口 | 单独色调 / 线型，表示同一入口的跨层实例关系 |

- 所有真实边仍从原 `edges` 读取，仅在两端都可见时渲染。不能为投影交叉增加节点、分割航道、加边或赋予寻路关系。
- 不要只移动节点图形而忘记更新航道：首次绘制与后续几何更新都必须从同一投影结果取得端点。可让线段中心到中心并被节点圆遮住，或统一裁到圆边，不能各处手写不同偏移量。
- 提前确定 SVG 分组顺序，使平面下方的节点、辅助线与航道仍可辨。低透明度平面不能吃掉负高度内容；标签与选择外环保持清楚。
- 不要求真实深度缓冲、边分段遮挡或复杂排序。可以采用简化 SVG 层次与适量透明度，但要在截图中看清谁在平面上方 / 下方。
- 原有选择、已拥有边和邻接边强调可沿用，不能让强调后的高度线看起来比真实航道更强。

## 四、子图前景与简略母图拓扑

- 进入子图后，前景是子图自己的固定无限参考网格、空间节点、脚点、高度线与航道；它仍是完整可探索图。
- 背景母图只保留当前已可见节点和真实连接关系。使用现有二维布局结果做简化拓扑概览，统一缩小并降低对比，不新跑一套布局算法。
- 母图背景**不绘制**参考平面、网格、刻度、平面投影点或海拔线，也不保留接近透明但仍存在的旧平面；正负高度不在概览中展开。
- 非关键母图节点用小圆点和细边即可，不保留完整图符、状态卡片或全部名称；共通入口节点高亮，可保留一个简短入口名称。
- 母图只读、不可聚焦，不写入前景节点视图映射，不遮挡前景命中区域。顶栏当前图名、面包屑、计数和详情仍全部属于子图。
- 返回母图时恢复其完整空间渲染及原有选择 / 探索状态，清除子图背景概览与跨层曲线，不把概览样式残留到主图。

## 五、共通逻辑入口与 Bézier 曲线

### 一份关系来源，不靠显示顺序猜入口

当前母图节点 D 已有 `childGraphId: branch`，但子图没有明确入口声明。最小方案：在现有 `DemoGraph` 中补 `entryNodeId`（branch 为 X；如统一要求也可声明 main 为 A），母图方仍复用现有 childGraphId。

- 通过“拥有该 childGraphId 的母图节点 + 子图 entryNodeId”解析共通关系。若后续当前版本已新增等价 parent / entry / owner 字段，直接复用，禁止重复建表。
- 逻辑身份由母图 ID / 入口 ID 派生；D 与 X 是它在各图中的局部别名和视觉实例。不要再用“第一个初始 Owned”“当前选中节点”“数组第一个节点”作为关联来源。
- 选择子图其它节点、添加随机节点或改变节点数组顺序后，跨层曲线仍连 D 与 X。关联无效时明确报告引用问题，不静默连到其它 Owned 节点。
- 两个实例的身份展示要一致，可将子图入口显示为“回声之门 · 子图入口”，保留局部 ID 供调试；不要继续把它们解释为两个毫不相关的地点。其它节点名称 / 描述不因本轮改变。

### 与原有状态的兼容边界

共通身份表达不要求重构 `nodeStates` 或建立共享状态服务。D 保持原有取得与进入门槛，X 保持子图初始入口的 Owned 状态；因此子图可进入时，两实例均为已拥有，不增加第二次取得或奖励。未进入的子图初始状态不反向揭示 D。

保留原有按图计数、选择与存储键；不要把 D 和 X 合并成一个全局状态项，从而减少节点数量、改写边 ID 或改变重置行为。本轮只需保证这个共通入口的可见身份与既有进入条件一致，不开发任意跨图节点共享机制。

### 曲线绘制

- 子图视图中始终有一条平滑二次或三次 Bézier，端点精确落在母图概览共通入口与子图入口的实际节点位置附近，不能连到子图脚点。
- 曲线单独分层，低于节点主体、区别于普通航道，不接收交互，不加入 `edges`、计数、揭示或寻路。
- 它表示“当前子图由母图中的此共通节点展开”，不表示跨层可通行的物理航道，不必遵循子图 z 投影。
- 两端必须换算到同一坐标空间。优先共享宿主 SVG / viewBox；若复用独立 SVG，明确通过矩阵或统一宿主坐标转换，不能混用逻辑坐标、CSS 像素与 viewBox 单位。
- 调整窗口、完成布局重绘或子图入口高度改变后，端点随之更新。复用现有 `renderConnectorSoon()` 的按需更新即可，不常驻逐帧轮询。

## 六、结构与交互约束

开工前简短说明现有 DOM / SVG 哪些层稳定、哪些层新增或替换：当前图参考平面、辅助层、航道层、节点层、只读母图概览、跨层曲线。不要为了这些层建立通用场景树。

- 平面 / 网格不随普通选中、探索、取得重建。节点状态变化更新对应节点及新显现边；切图、重置、随机加点引发的原有结构重绘可继续沿用。
