# 用户自定主题编辑器尺寸与性能优化任务

> 本文回答：如何解决用户自定主题编辑页过小、内部容器挤压和编辑时显示性能不佳的问题。

## 1. 目标

在不改变用户主题权限、安全校验和数据协议的前提下，建立可用的桌面三栏编辑工作区，修复弹窗宽度限制和旧 JSON 保存路径，降低编辑过程中的整块重绘与布局抖动。

## 2. 已确认问题

| 问题 | 原因 | 影响 |
|---|---|---|
| 编辑页过窄 | `.modal-panel` 的基础宽度仍为 `min(560px, 100%)`，打开时只设置了 `max-width` | 三栏内容被压缩 |
| 内部区域高度受限 | 检查器固定 `max-height: 480px`，弹窗主体与检查器滚动关系不清晰 | 内容需要多次滚动，预览面积不足 |
| 保存逻辑残留 JSON 路径 | 编辑器已移除 JSON 文本框，保存仍查询 `[data-user-theme-presentation]` | 可能把表现配置按空对象提交 |
| 预览扩展性不足 | 预览和编辑器节点没有明确的局部更新边界 | 后续组件增多后容易出现闪烁与布局抖动 |

## 3. 目标布局

```text
┌──────────────────────────────────────────────┐
│ 标题                                      × │
├────────────┬───────────────────┬─────────────┤
│ 主题导航   │ 安全预览画布       │ 属性检查器  │
│ 固定       │ 独立滚动           │ 独立滚动    │
├────────────┴───────────────────┴─────────────┤
│ 能力状态 / 校验信息        取消   保存并应用 │
└──────────────────────────────────────────────┘
```

桌面端目标列宽：`180px / minmax(420px, 1fr) / 360px`。

## 4. 实施方案

### 4.1 弹窗尺寸

- 为用户主题弹窗增加专用标识，避免影响其他弹窗；
- 宽度使用 `min(1180px, calc(100vw - 48px))`；
- 高度使用 `min(820px, calc(100vh - 48px))`；
- 弹窗头部和底部固定；
- 中间工作区负责滚动；
- 移动端保留 `calc(100vw - 24px)` 的安全边距。

### 4.2 工作区容器

- 左侧导航固定宽度，内容过长时只横向滚动；
- 中央预览设置最小宽度和最小高度，避免被检查器挤压；
- 右侧检查器独立滚动，不再固定过小高度；
- 窄屏切换为导航横向滚动、预览、检查器的纵向结构；
- 使用 `min-width: 0`、`minmax()` 和 `overflow` 防止横向溢出。

### 4.3 保存数据路径

- 删除对旧 JSON 文本框的读取；
- 保存直接提交编辑会话中的 `draft.presentation`；
- 颜色、图层、组件控件只修改 session draft；
- 保存失败时保留 session draft，不覆盖已应用主题；
- 继续由 `UserThemeService.apply()` 执行完整能力、revision、资源和安全校验。

### 4.4 预览更新边界

- 颜色输入只更新预览 CSS 变量和对应色值文本；
- 锚点输入只更新当前组件定位状态；
- X/Y 输入使用 `requestAnimationFrame` 合并连续事件；
- 区域切换只切换当前预览节点，不重建整个弹窗；
- 结构变化才局部重建组件列表；
- 预览区域增加 `contain: layout paint style`，限制布局影响范围；
- 预览仍使用转义后的安全字段，不开放 CSS、HTML、Selector 或脚本。

## 5. 响应式规则

| 宽度 | 布局 |
|---|---|
| ≥ 1000px | 180px / 自适应预览 / 360px 三栏 |
| 760–999px | 导航 + 预览两栏，检查器独占下一行 |
| < 760px | 导航横向滚动，预览与检查器纵向排列 |

## 6. 验收标准

- 桌面端编辑页不再被 560px 宽度限制；
- 预览和检查器有足够可用高度；
- 各区域滚动互不干扰；
- 保存不会访问已删除的 JSON 控件；
- 未修改表现配置时，保存不会清空 `presentation`；
- 调色、锚点和偏移输入不触发整页重绘；
- 未获得 Active Affector 时编辑器仍完全只读；
- 移动端无横向溢出；
- `npm test`、`npx tsc --noEmit`、`npm run check:architecture` 和 `npm run build` 通过。

## 7. 实施结果

- 用户主题弹窗已使用专用 `panelClass`，桌面端不再受基础 560px 宽度限制；
- 已建立桌面三栏、平板双栏和手机纵向布局，并分离预览与检查器滚动；
- 已移除旧 JSON 文本框保存路径，保存直接提交 session draft；
- 颜色预览更新已使用动画帧合并，预览区域增加布局/绘制隔离；
- 全量测试 112 个文件、1045 项通过；类型检查、架构边界检查和生产构建通过。

## 8. 状态

已完成。
