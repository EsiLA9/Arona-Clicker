## Constraints

- 复用 0190 已交付活动/招募/Route 类型及 U3 已交付 encounters；node ID、locationId、encounterId 各自独立，不相互推导。
- 固定节点顺序和活动度；沿用 0190 中可复用节点与实际内容 ID。仅为缺失节点分配稳定且唯一的 ID，并由 U5 校验。
- Node 6/10 入队在本节点活动前；不加入队确认或移动 Click。活动结果、战斗、入场与结尾文本按事件发生时点输出。
- 线索、代币类叙事只作为事件日志文本，不创建任何持久状态、奖励或分支。
- 三场战斗的成功/失败/平局、Boss 混合目标、reload 和意图文本服从 U3 与 R08 为导演内容候选/原型暂定（按授权可实施、2026-10-04 可修订）；R06/R10/未决 R09 继续标记原型暂定。
- 不猜 0190 Route schema；若不能直接组成 ordered nodes，先停止调整接口边界。
