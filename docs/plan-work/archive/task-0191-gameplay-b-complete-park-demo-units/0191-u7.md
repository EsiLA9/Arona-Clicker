## Constraints

- 只添加/调整回归测试、README 的实测记录和本 Unit Receipt；发现实现缺陷退回对应 Unit，不在验收单修 Runtime/UI/content。
- 通关路线至少一个固定 seed 可完全复现；另有失败与平局 fixtures，按已有 Runtime API 构造且不把 seed 当玩家输入。
- 对账总 Click = 11 次非战斗活动 + 三场实际战斗结算轮数；活动度、招募和自动转场不插入额外 Click。
- 浏览器记录运行环境、seed、各战斗轮数、总 Click、开局/终态和实际可观察的运行状态；只记录实际结果，不预填成功结论。正式入口固定使用演示 seed，没有失败/平局切换输入；这两种终态由确定性 Runtime 夹具回归，不为浏览器增加临时控制项。
- Boss 文案与冻结目标一致；终态后重复输入不追加事件；R08 为导演内容候选/原型暂定（按授权可实施、2026-10-04 可修订），其他 provisional 规则和候选 camp 数值均不写成用户确认。
- U7 含 README 的实际 seed/运行记录；因已完成 Runtime 和 UI、不新增机制实现，本 Unit 仅归并整局回归与实测说明。若必要净改动低于 200 行，先核对验收覆盖并按实际范围收窄预算，不人为填充实现，保持总文件≤5。
