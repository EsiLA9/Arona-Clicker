## Constraints

- 敌人 HP/ATK/DEF/行/意图定义按 0182/0186 和前置已交付角色/内容 ID；没有依据的 ID 不得自造。
- 意图循环确定，不增加 RNG；普通冲锋、烟花范围攻击、Boss 混合目标和固定伤害使用已交付机制。
- 烟花手偶数轮必须配置可读 reload/no-op，空目标，无伤害；不能模拟成无效普通攻击。
- 领头受伤优先只配置为 U1/U2 定义的上一轮实际 HP 变化反应；不以当前 HP 或永久低血状态替代。
- Boss 不能写成所有后排或全排；文案/意图目标与实际冻结目标一致。
- R08 为导演内容候选/原型暂定（按授权可实施、2026-10-04 可修订）；R06/R10/未决 R09 与 camp 数值仍按原型暂定/候选；不修改 AC 或运行结算。
