## Constraints

- 从最终 Battle Runtime 的实际结果取得上一轮受伤信息；优先比较同一敌人结算前后 HP，不用原始攻击伤害或“HP 小于上限”代替。
- 每轮准备只读取紧邻上一轮标记；不能跨空轮、Click 或战斗残留。
- 受伤后优先执行一次；下一轮恢复基础交替位，不重置序列。优先动作轮若再次实际受伤，仅为紧接下一轮生成新标记。
- fixed-damage 按锁定 targetIds 各应用 amount=1，不经过 ATK−DEF，逐目标产生 HP Delta/log。
- reload/no-op 保留意图记录，targetIds 为空，HP delta 为零，不生成普通攻击。
- 用户确认/原型暂定状态不变；使用 U1 已验收的准备契约，不另改 model/prepare。

## Completion Criteria

- [ ] Boss 混合目标逐个固定扣 1 HP；普通 ATK/DEF 与护盾/净值规则独立。
- [ ] reload/no-op 无目标、无伤害、无其他 HP 副作用，但预告/日志保留。
- [ ] 只有上一轮结算导致敌人 HP 实际下降才触发领头下一轮一次性优先冲锋；测试未受伤、纯盾吸收、连续受伤。
- [ ] 优先冲锋不重置基础序列；无新受伤时恢复原交替顺序。
- [ ] Runtime 每轮只传最近结算受伤集合；终态和新战斗不残留记忆。
- [ ] 定向结算/runtime/敌意图回归及类型检查通过；不改 0190 camp 终态。
