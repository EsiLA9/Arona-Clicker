## Constraints

- 只从实际 main/view/Route Runtime 接口连接已验证 Route；UI 只消费只读 View，不写入机制状态。
- 玩家只有 Click；滚动、浏览或重复 getView 不推进状态。点击只处理输入开始时显示的活动或一轮战斗。
- 视图和日志准确显示节点、活动剩余、队伍 HP/人数、敌方意图范围、结局和事件文本；Boss 必须描述我方存活前排全体及一名最低 HP 存活后排；该 R08 文案为导演内容候选/原型暂定（按授权可实施、2026-10-04 可修订）。
- 入口级测试与人工冒烟使用原型包实际启动命令；README 和整局 seed 记录由 U7 负责，不依赖 AC。
- 无常驻线索状态、额外输入、存档、迁移、成长或分支；R06/R08/R10/未决 R09 按原型暂定状态标注，R08 可于 2026-10-04 修订。
