## Constraints

- 混合目标只含准备时存活目标：所有存活前排加一名存活后排最低 HP；并列时按实际队列顺序选一名。
- 固定伤害使用独立效果语义，不能将 ATK=1 或普通攻击公式当作固定 1。
- reload/no-op 有可观察的意图身份/文本，准备目标为空；实际无伤害结算由 U2 负责。
- 为领头定义 `previousRoundDamagedEnemyIds` 可选输入与 per-enemy `previousRoundDamageReaction` 意图；只响应紧邻上一轮结算后实际 HP 下降。优先动作不重置基础轮序；U2 负责从最近一次 `lastResolution.deltas` 生成并仅传入下一轮。
- 准备时冻结目标，不因后续 HP 改变重选；意图生成不消耗随机数。
- 三种基础配方输出为用户确认；R06/R10 与未决 R09 保持原型暂定；不修改 AC 或 0186。
- 若实际 target/effect 类型要求修改白名单外文件，停止并由上游重划 Unit。

## Completion Criteria

- [ ] 准备类型表达 Boss mixed target、fixed-damage 和显式 reload/no-op，不模糊复用普通攻击。
- [ ] Boss 目标快照包含所有存活前排及队列顺序第一名最低 HP 存活后排；测试多后排、并列 HP、无存活后排及无存活前排。
- [ ] reload/no-op 在准备视图可识别且 targetIds 为空。
- [ ] 传入上一轮实际 HP 下降敌人 ID 时，领头下一轮优先选配置的冲锋反应；不传入时使用基础循环；反应不重置基础循环。Runtime 数据由 U2 接入。
- [ ] 准备预览冻结结果、读视图不消费 RNG；battle-prepare 与敌意图定向回归通过。
- [ ] R06/R09/R10 暂定状态与用户已确认项原样保留。
