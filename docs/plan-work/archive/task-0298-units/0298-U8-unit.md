# Unit 0298-U8：单位目标点击、拖拽与编辑锁定

## Goal

在现有单位目标上实现独立编辑入口、点击 / 键盘确认与无作用线拖拽，统一发送既有草稿命令。

## Must Read / Read Set

Task P4、U5 / U7；关系交互类、Controller 查询与草稿命令 adapter、Map renderer 与 CSS、Map 目标命令契约、`controller-actions-operation.ts` 的目标委托与浮层关闭（只读）、交互测试。

## Context Budget

15k–30k token，历史 0；Optional 为 Pointer 事件的相关现有实现；超预算拆分。

## Confirmed Facts

关系公开 canSelectTarget 与 Owner 候选；单位 DOM 已携带 object key；行为牌点击换牌已独立存在。prepared / ability / item 的草稿目标命令均已有，敌方无控制权限。

## Constraints

最高优先级锁定来源；6px 拖拽阈值前不抢换牌点击；拖拽副本纯展示且 pointer-events:none。最上层 Pointer 命中决定对象，不透过遮挡层选背后目标；遮挡可通过展开 / 键盘 / 现有目标按钮处理。编辑只更新属性，确认才调用命令；无效释放 / Escape / cancel 零命令，stale 交 Owner 拒绝。

结构：每个可改选行为一个独立编辑按钮；拖动期间一个临时副本，无 SVG / 几何锚点系统。Controller 继续一次局部刷新，preserve key / scroll / Popover；失效版本取消捕获与副本。

## Completion Criteria

- [x] 编辑 > 浮层 > 固定 > Hover / Focus；拖动时来源保持，合法命中有独立反馈。
- [x] 点击 / Enter / 拖拽均至同一确认 adapter，成功一次命令，无效释放或取消零命令；尾随 click 不触发换牌。
- [x] 版本失效 / reset / dispose 不残留临时副本或捕获；敌方不可控制。
