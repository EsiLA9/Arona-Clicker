# Task：独立节点探索 Demo 的桌面视觉与世界线偏移表现

状态：completed — 视觉与三方案已完成；原说明：已核对本地版本；用户选定桌面美化、保持玩法，并追加更有世界线偏移感的母图 / 子图设计；本 Task 纳入三种可切换的表现方案，等待其他模型执行。

## 目标

在已经能操作的 TypeScript 节点探索 Demo 上做一轮明显可见的桌面美化，使画面更像一张清楚、轻盈、有层次的探索地图，方便亲自体验和讨论。

保留现有浅色、柔和蓝色方向，重点改善画布、节点、连线、详情面板和操作反馈，并把母图 / 子图切换做成可体验的“世界线偏移”：看得见偏移来源、分支空间与返回关系。这仍是可删除的独立实验，不建立正式游戏 UI、设计系统或节点框架。

本轮只编写增强 Task，实际修改由后续模型执行。前置成果见 [[docs/plan-work/task-0302-standalone-node-graph-ui-demo]]；0302 保持 completed，本文描述下一轮独立结果。

## 用户裁定与边界

- 不新增玩法规则。允许下文规定的世界线表现模式、只读对照与过渡交互；探索 / 取得仍免费，四态转换、相邻揭示与子图进度规则保持现状。
- 只考虑桌面浏览器，主要观察 1440×900，顺带检查 1280×800；不做手机、平板、触屏或窄屏适配，不要求这些视口验收。已有窄屏样式可保留，但不为其投入改造工作。
- 保留当前已有的随机节点、布局求解器、母图背景扁平 / 倾斜能力。允许为世界线表现改进进入 / 返回动画及其清理，不把现有 220ms 淡出当作必须原样保留的设计。0302 最初对随机生成等内容的排除不能用来删除当前本地版本已经存在的功能。
- 不添加探索点、消耗、补给、钥匙、节点类型规则、任务、奖励、成就、收藏、解锁条件、战斗或剧情。装饰图符不能变成新机制。
- 保持 TypeScript、原生 DOM / SVG 与现有 Vite 入口。不增加依赖、图片 / 字体下载、框架、图库或后台服务。
- 不接入 AronaClicker 的任何业务模块或存档；仍只保存当前页面会话的内存状态。
- 按 Demo 规模实施：不预建组件库、主题系统、全局样式规范、自动化测试设施或额外开发控制台。

## 视觉施工要求

### 1. 桌面构图：让画布成为主体

- 沿用现有图名、面包屑和动作，不新增大标题区、介绍页、装饰性统计或与节点操作无关的文案。
- 顶栏收紧成一条清楚的工具栏。图名 / 路径是定位信息，返回是导航动作，随机与重置是次要工具；用间距、字号和按钮层级区分，避免所有元素同样抢眼。
- 1440×900 下，画布明显占主要宽度，右侧详情约 280–320px；尽量让顶栏、图与详情主操作同屏可见。允许合理调整当前页面最大宽度、间距和画布高度，不强行填满屏幕。
- “已拥有 / 已认识 / 待探索”沿用真实计数，可做紧凑的数字与标签排列；图例弱于节点与主操作。不新增会透露隐藏节点总数的百分比或完成度条。
- 调试区保持默认折叠。随机节点功能仍可直接找到；不隐藏到多层菜单，也不添加新的配置面板。

### 2. 画布：增加地图感，控制装饰

- 将大片纯白画布整理为有轻微边界感的地图表面：低对比浅蓝底、很淡的点阵或网格，二者选一种即可；与外围页面背景区分。
- 背景只用于区分空间、支撑定位，不画暗示隐藏节点位置的光点、轮廓、路径或地标；不要铺满插画、复杂等高线、动态星空或粒子。
- 统一圆角、边线、阴影强度，避免顶栏、画布和面板都使用厚重阴影。画面重点应落在节点与当前选择。
- 沿用 `viewBox` 与当前布局结果；不能通过重新求解、拖拽、缩放工具或改图结构来掩盖视觉问题。不得用 `overflow: visible` 把节点画到面板或工具栏上。

### 3. 节点：精致、可读，状态明确

- 保留圆形主体和现有四态语义，以细节、图符和层次增强辨识，不扩大为复杂节点卡片。
- Frontier：保留问号、浅色和虚线，未知内容仍未知；Known：清楚的边线与可读名称；Owned：柔和但鲜明的蓝色填充和拥有标记；Selected：独立外环。Hover / Focus 不覆盖或混淆这些状态。
- 对固定节点，可用小型本地 SVG 线条图符替代圆心大字母，例如营地、桥、门、瞭望点；依据现有名称作视觉映射，不新增节点类型或业务字段。字母 ID 可作为弱化辅助或仅在调试区保留。
- 图符映射保持在视图内，随机节点使用统一的通用图符；Frontier 一律显示问号，不从图符、角标、颜色或可访问名称提前透露真实身份 / 子图属性。
- Known / Owned 的 D 可使用入口图符；实际进入仍受原有 Owned 条件限制，不新增按钮或绕过门槛。
- 标签与图符在桌面可读，标签不压在线上、外环或相邻节点上。优先使用描边底衬、轻微底板与合理标签位置；保持现有布局与命中范围，不能只把节点 / 字体越做越大。
- 选中外环、勾选角标、节点主体应构成一套视觉比例。同图状态反馈不改变节点坐标和命中范围；世界线切换允许整层变换，过渡残影不可交互，完成后前景显示与命中必须一致。

### 4. 连线与母图：显示关系，保留层级

- 连线仍只显示两端均可见的实际边。普通边弱化，Owned–Owned 边更清楚；可高亮当前选中节点的直接可见连接，帮助读图。
- 高亮只改变表现，不自动选择邻居、不绘制 Hidden 端点的边、不推断整条路线；取消选中或切图后无残留。
- 线宽、端点、颜色统一，不能压过节点。无需行进光点、持续流光或路径动画。
- 母图的具体构图与过渡按下方“世界线偏移设计”实施，保留扁平 / 倾斜投影能力。低对比、来源节点可辨、前景优先，不让母图标签争夺注意力。
- 母图继续不可点击、不可聚焦，不能遮挡前景命中区域；相位对照期间也只读。不新增真实 3D 系统或多层图导航。

### 5. 详情面板：操作层级清楚

- 沿用节点真实名称、状态与描述；用排版把“节点身份 → 描述 → 当前操作 → 最新反馈”组织清楚，减少到处使用胶囊和分隔框。
- 当前主要动作突出，Owned 的普通节点使用安静的已拥有提示；不为已拥有状态制造无作用的按钮。
- 当前面板顶端可以复用节点图符作视觉锚点；未知节点仍用问号与通用提示。
- 探索 / 取得的反馈显示在固定区域，避免每次改变文字后把主要按钮推来推去。不新增奖励弹窗、消息列表、历史记录或剧情文案。
- 操作面板保持现有直接操作方式，不新增必须悬停才可见的按钮，也不增加额外弹窗或交互步骤。

### 6. 轻量反馈与 DOM 连续性

- 保留按钮 hover、按下、键盘 focus；节点选中、Frontier → Known、Known → Owned 可以增加约 120–220ms 的颜色 / 不透明度反馈。新邻居可短暂淡入一次。
- 进入 / 返回过渡按下方方案改进，保留 `prefers-reduced-motion` 处理。无持续呼吸、旋转扫描、常驻动画循环、粒子或拖慢点击的演出；动画不能延迟探索 / 取得的状态提交。
- 沿用节点按 ID 保存的视图与局部更新。同图选中 / 探索 / 取得不重建页面、整个 SVG 或未改变的兄弟区域；切图、重置、随机加点和已有跨断点重绘保持原行为。
- 新增 wrapper / SVG 装饰须有布局、状态或读图用途。开工时用几行说明哪些区域保持稳定、改哪些渲染节点即可，不另写结构文档。
- 不用延时器控制玩法，不改变求解器时机。可调整过渡锁和取消清理以支撑新表现；切图 / 重置后一次性视觉类、对照状态与旧动画不得残留。

## 世界线偏移设计：三种可比较的表现

用户授权的是探索更有趣的母图 / 子图设计；以下三种是本 Task 提出的具体方案，不表示真实游戏已经采用相应世界线机制。实现三个小型可切换的视图，共用当前两张图、同一份状态与一套节点渲染；不做三个独立 Demo。

### 方案比较

| 方案 | 进入与停留体验 | 表达重点 | 主要取舍 |
| --- | --- | --- | --- |
| A · 偏移叠层（推荐默认） | 母图退后成为一张薄投影，子图由入口处展开至前景 | 从母图的某个锚点偏移出分支空间 | 与当前背景结构最接近；需处理好锚点和前后景关系 |
| B · 分歧轨迹 | 母图收成后方的小幅来路图，分歧轨迹引向前景子图 | 当前分支从哪里分出、如何回去 | 来路最清楚；轨迹过强会被误认成可走的图边 |
| C · 相位对照 | 平时子图清楚、母图轻微错位；主动对照时母图显露，子图退为残影 | 两个独立空间同时存在，当前处于其中一层 | 世界线感更强；需明确只读状态，避免叠图难读 |

三者成本相对高低是本轮设计判断，不要求精确工期。A 优先完成，B / C 复用其投影、锚点和过渡；不扩张成布局系统或渲染引擎。三种方案都要能实际切换观察，不能只把 B / C 写成未实现的说明。

### 共通语义：偏移来源是真实的，因果关系不虚构

- 母图 D 是偏移来源，子图 X 是另一张图的入口，二者是“由此进入”的关系；不声称它们是同一节点的过去 / 未来，也不伪造对应地点、时间轴或跨图影响。
- 保留真实图名和面包屑，可补一句紧凑定位信息“由「回声之门」偏移”。主图标作“母图”，当前子图标作“偏移分支”，不要展示无来源的偏移率、世界线编号、危险度或伪造参数。
- 母图沿用冷蓝灰、子图可用少量青蓝描边 / 表面强调来区分层次；节点四态仍沿用原有颜色语义，不因切换方案而改变状态含义。
- 母图投影只画当前已可见内容，来源 D 可用稳定的锚点环。子图探索不会改变母图进度；母图背景不补画未发现节点。
- 三种方案都保留单一可操作前景。视觉轨迹、过渡残影和母图没有节点事件、tabindex 或面板操作，不会影响计数 / 随机连接 / 邻居揭示。
- D 与 X 之间的视觉关联单独画在装饰层，采用不同于普通图边的细虚线 / 淡带，明确终止于锚点，不加入任何图的 `edges`。Frontier 的 D 不提前出现偏移关系或子图预览。

### A · 偏移叠层

- 点击“进入子图”后，以 D 的可见位置作为来源：母图整体缩小并退后，前景子图由来源附近淡入 / 展开，最终形成“母图在后，当前偏移分支在前”的稳定构图。
- 稳态保留母图 D 的来源环与子图 X 的入口联系，二者间可以有一条很淡的偏移引线。母图不是任意摆在右下角的缩略图，构图必须让人看出它与前景入口有关。
- 子图节点使用原布局坐标与求解结果。偏移通过整层的平移 / 缩放与背景投影完成，不逐个挪动节点以制造对应关系，也不把前景长期倾斜到难以操作。
- 返回时反向收拢偏移层，母图回到前景，最后恢复 D 的选择与焦点。进入、返回两方向应表达同一组空间关系。

### B · 分歧轨迹

- 母图投影集中到画布后方一侧，保留可识别的 D；从 D 引出一条弯曲的淡轨迹，落在子图 X 附近，前景子图占主要面积。
- 母图小图表达来源，轨迹表达分歧，不做并排等权双画布或可点击小地图。子图节点仍清楚、正立，所有当前可见节点与标签可用。
- 进入时只做一次沿轨迹方向的短展开，返回时沿相反方向收回；轨迹不持续流光、不模拟旅行进度。
- 如果空间有限，优先简化母图标签与轨迹装饰，保持前景完整；不能裁掉当前图来腾地方。

### C · 相位对照

- 默认仍以子图为清楚的活动层。母图以低对比、轻微错位的只读残影保留，不将两张独立图的节点强行一一对齐。
- 本方案显示一个原生“对照母图”切换按钮，`aria-pressed` 表达是否开启；不依赖悬停、长按或隐藏快捷键。
- 开启对照时，母图变清楚、子图退为淡影，同时明确显示“母图对照 · 只读”；当前实际图仍为子图，选中 ID、进度和详情仍属于子图，不假装发生了一次返回。
- 对照期间，前景节点与探索 / 取得 / 进入动作暂不可操作，防止点到正在淡出的层；对照按钮、返回、重置和视图模式切换仍可用。退出对照后恢复原子图的选中与动作，不重建探索状态。
- 不把进入 / 退出对照当作探索事件，不写业务状态，不将母图设置为当前图。切换方案、返回或重置都应结束对照。

### 最小模式控件与实现边界

- 在画布头部提供紧凑的“偏移叠层 / 分歧轨迹 / 相位对照”三选一控件；默认 A，不占满顶栏，也不新增配置页。主图不显示无效果的对照按钮。
- 原“扁平 / 倾斜”作为母图投影的次要样式能力保留；它与三种空间构图分开，不能仅把现有两个 CSS 变换改名就算实现三方案。
- 模式切换只修改很少的展示状态和图层样式，不调用进入 / 返回操作，不重置图、重新随机、改变节点坐标或重复求解。模式在往返期间保留，重置 Demo 后恢复 A、扁平投影、关闭对照。
- 每次进入或返回只提交一次实际目标图。建议先提交目标图，把旧画面作为不可交互的短暂残影；动画完成只清理展示，不再提交一次切图。允许使用必要的取消句柄，但不要新增通用动画管理器。
- 过渡整体约 180–320ms，减少动态效果时直接得到同样最终画面。重置能立即取消未完成动画；旧回调不得在重置后把玩家重新带入子图。
- 对已有 `renderBackdrop()`、`backdropAnchorId` 和过渡代码作局部扩展即可。新增残影 / 引线不加入 `nodeViews` / `edgeViews`，不触发图的布局算法。

### 判断方案好坏的体验问题

体验者应能直接回答：“我现在在哪一层”“从母图哪个节点偏移而来”“怎样回到母图”“对照是在看母图还是已经回去了”。若只能看出三种背景花纹不同，或需要读长说明才能理解，就没有达到本节目标。
