# Unit 0298-U18：可用的卡牌高亮与目标入口

## Goal / Read Set

把 U17 真实卡牌目录接入当前行为牌、Hand 展示和独立目标候选入口，使玩家无需作用线即可点击 / 拖拽改选卡牌；显示真实 sCost 余额和减免说明。读 map renderer、共享 interaction、Workspace action DTO / Runtime 投影、Controller 既有确认 adapter、CSS、Workspace / interaction 测试及 frontend-design 约定；预算 18k token。

## Confirmed Facts

同一领域牌已可跨视觉副本高亮，但 renderer 尚无 card object key。beginEdit 会通过 opener.click 关闭换牌浮层；若该 opener 同时是合法卡牌目标，必须避免关闭动作误作目标确认。仅给浮层内隐藏牌加 key 无法覆盖被遮挡目标选择。

## DOM / Update Sketch

复用 UnitFace + unit-card-stack（稳定 region）及既有 target-picker。当前行为牌、真实 Hand 浮层展示追加 Owner object key，不给未选 Command offer 建实例。新增一个卡牌目标组（1 wrapper + 1 候选容器），每个合法对象一个普通选择按钮及说明，不构成第二套 Hand；该代理只选择目标，不 Swap / Commit。所有文本转义，长列表使用原局部区域可访问滚动。

交互 session 只改角色属性；确认通过既有 Controller adapter 更新草稿并 requestMapWorkspaceRefresh，一次 Map patch，保留 Frame / 三栏 / Flow 滚动 owner。局部目标组可替换，复用 focus / region key；Popover 生命周期仍交既有委托。新选择入口命中使用同一 Owner candidates，不新增状态 Owner 或 scheduler。
