# Unit 0298-U4：单位关系的共享视觉角色

## Goal

给当前单位 / 行为来源建立一致的身份标记和 Source / selected-target / Candidate 视觉适配，保持纯表现。

## Must Read / Read Set

Task 0298 P1、U3 Receipt；frontend-design skill、UI overlay、`ui-style/foundations.md` / `patterns.md`（本会话已读）；Map renderer / CSS、关系契约与 projector、Workspace UI 测试和 `map-dom-updates.ts`。

## Context Budget

10k–25k token，历史 0；Optional 为直接类型调用方；默认不读旧 Operation 全实现与独立编辑器，超预算拆分。

## Confirmed Facts

P0a active View 已提供 relations，U3 已验证 UnitFace / 当前牌 / Popover / Flow 基础；当前单位行为来源有 preparedAction / ability / item，敌方来源为单位且目标未知。

## Constraints

来源标记与目标包围角框不同；中性颜色角色、双标记分位；只消费关系，不自行计算候选。使用已有根节点属性 / CSS 伪元素，不新增装饰 wrapper。无关节点不替换；原生 focus-visible 继续独立可见。

## Explicit Non-goals

不做完整交互状态机、目标命令、卡牌效果或作用线；实际 Hover / Focus 接入留给 U5，P1 浏览器验收在接入后记录，不提前宣告。

## Stop Conditions

沿用六项停止条件，代码约 300 行以内，超过预算先拆分。

## Completion Criteria

- [x] 当前来源 / 单位身份和公开未知敌方信息可从 DOM 定向映射。
- [x] 给定关系可区分来源、选定目标、其他候选、双角色与无目标，更新不替换 DOM、不发命令。
- [x] 清除角色不影响焦点 / 滚动 / 无关状态；普通聊天与历史 Flow 不变成目标。
