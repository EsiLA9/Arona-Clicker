# Unit 0298-U11：MapRun 卡牌身份与有效期

## Goal

为已有 Hand、实际选中的 PlayerCommand 与敌方公开行为提供 Owner 可解析的卡牌引用；视觉副本不创建领域对象。

## Read Set / Context Budget

Task P0b、MapRun snapshot / service（snapshotOf、previewActions、Override）、行动 preview resolver、Runtime 查询门面、现有关系与 MapRun 测试；架构 / 测试约定。预算 15k token。

## Confirmed Facts

`GameplayBActionPreview` 已验证 Hand 内 actionId 唯一、最多三张且按抽取顺序固定；`MapRunService` 持有 run / node / activity / round、Hand 与 Override；Runtime MapRunQuery 只读。未入 Hand 的替换候选当前只是命令选项，不是独立战斗牌。

## Constraints

Hand 牌身份以 Run / Map / Node / activity / round / Character / action 区分，换牌只改变准备态，不复制或重排 Hand；跨轮引用失效。未入 Hand 的命令牌仅在实际选中时出现；换下后引用失效，后续卡牌目标命令必须清理失效引用。敌方行为只读，不暗示目标已确定。数据脱离 Owner 并冻结；查询不写草稿 / RNG / 余额。
