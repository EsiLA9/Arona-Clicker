# U18 Shield Workspace 屏幕验收需求单

状态：待人工执行。自动化 UI/Flow 测试已经通过；它们不代替浏览器屏幕验收。此前浏览器自动化连接超时，本轮也没有形成可观察的人工操作记录。

## 验收目标

确认用户能通过本地试玩台进入 Shield 示例，并在 Workspace 看到独立 Shield 数值和最近一次 Commit 的逐击结算。

## 步骤

1. 在开发版打开迷你控制台，运行 `startMap gameplay-b:map:shield-example --enter-office`，确认进入“友方护盾演练” Map。
2. 进入“两轮护盾演练”遭遇，为白子选择“护盾支援”，将主目标设为芹香；预览费用应显示消耗 1 点专注。
3. 提交第一轮。芹香单位信息应单独显示 Shield 1、HP 8/10；最近提交记录应显示获得 Shield 3，以及训练机器人伤害 2、Shield 吸收 2、剩余伤害 0。
4. 第二轮让白子选择“观察”并提交。芹香应显示 Shield 0、HP 7/10；最近提交记录应显示伤害 2、Shield 吸收 1、剩余伤害 1。
5. 确认 Shield 不并入 HP 条，也不显示为 Status 条目；最近提交记录顺序与战斗队列一致。
