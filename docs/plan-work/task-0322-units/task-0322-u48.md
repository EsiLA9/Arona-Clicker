## Confirmed Facts
| 事实 | 依据（路径 / 符号） | 备注 |
| --- | --- | --- |
| Talklet delivery 使用 `advanceStory(token)` 确认，Click button 使用 `clickSend(token)`，choice 提交稳定 optionId | `src/arona-clicker/services/story/story-service.ts:advanceStory/clickSend` | 两个等待阶段不再由旧页式执行器合并 |
| press=N 表示 N 次有效输入；没有隐含的额外确认 | `src/arona-clicker/services/story/story-node-player.ts:submit` | 单独确认由后继 Click 表达 |
| 重读守卫检查已记录的 Talklet ordinal，不将 Click/Operation 计入正文阅读 | `src/arona-clicker/services/story/story-entry-selection.ts:guardPrereqsMet` | 需确认正文真实交付后再选择分支 |

## Constraints
- 保留旧测试所验证的门控、返回栈、奖励抑制、守卫拒绝与真实阅读行为。
- 按 Task 明确的逐Talklet delivery和独立Click改写，不删掉真实业务断言。
- 不修改生产源码或共享夹具。
