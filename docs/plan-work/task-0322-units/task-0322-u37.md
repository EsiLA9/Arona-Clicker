## Constraints

- 不直接编辑`engine-defs.gen.json`；源类型与`editor-extras.ts`为唯一Schema源。
- 引用覆盖goto/insert、button/choice transfer、EntryRequest/card、state命名参数、travel、主题与条件。
- story分支条件只在choice.options.condition扫描。
- 不因未知字符串候选扩大引用表语义；明确字段必须使用准确表和路径。

- [ ] Story reference scanner只按nodes与命名动作路径声明故事内引用。
