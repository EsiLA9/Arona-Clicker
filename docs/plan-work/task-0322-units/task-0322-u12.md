## Constraints
- cursor元素为`{playback: StoryNodeSnapshot,isReplay,lastChoiceIndex,flags}`；global/chats外层集合保留。
- 完成结算先移除结束session，再应用奖励/完成日志与事件，避免同步事件启动新链被旧run覆盖。
- 奖励/root/terminal按上述确认身份；replay抑制奖励、storyLog、cooldown、block和storyCompleted。
- flags、choice和replay元数据必须按session隔离；restore不执行动作、不重复readlog，不兼容旧格式。
