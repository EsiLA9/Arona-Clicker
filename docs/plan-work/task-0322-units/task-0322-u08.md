# Unit 0322-U8：Action宿主静默拒绝边界

## Goal
在调用旧领域Effect前拒绝已知会被EffectEngine静默吞掉或无法按来源路由的组合；不改变Effect批次与旧StoryService合同。

## Read Set / Confirmed Facts
- Task§13及U4适配器；`state-mutation-service.ts` 的 `canMutateSpot`、`setSpotLevel`、`setManager`、`acquireCharacter`、`addAffectionExp`。
- `runtime-wiring.ts` 的 Init Spot guard：global Spot可写，否则必须属于当前activeInit。
- `effect-ops.ts` 丢弃 `addAffectionExp` 返回值；未拥有Variant时Mutation返回 `ok:false`。EffectEngine仍按当前状态先统一求值，再按顺序调用mutation。
- `color-system.ts/handleThemeEffect` 的 ephemeral为单槽临时层，scope为area/student只传colorGroup、palette、tokens、nodes；背景层不转发。`runtime-effect-reactor.ts` 的 story presentation依赖旧storyCompleted清理。
- `chat-flow-service.ts` 的Overlay/openingTitle事件不携带owner；它们只能指向当前全局演出流。入口卡片的事件只携带targetStoryId，无法保留EntryRequest的owner/type/intent；openTitle省略title会依赖旧UI cursor回退。

## Constraints / Non-goals
- `preflight`只核静态引用和支持能力；state动态资格只在execute即刻检查，允许前序Action改变后序资格。动态失败允许已有前序副作用，不回滚。
- 同一state.effects按作者顺序做virtual roster检查，允许先grantCharacter后addAffectionExp；EffectEngine仍只调用一次，不复制表达式求值。跨Action批次以每次执行时最新state为准，支持先grant再加好感；不对整分支做动态状态投影。字面数值和表达式统一沿用领域的零增量/上限等政策，applied不保证正增长。
- 旅行/状态更改后不回滚。资源ID可由运行时自定义，本Unit不以Registry资源表限制。
- 明确拒绝无效Init Spot写入、未拥有角色好感、story生命周期实体表现、ephemeral主题（包括省略scope）、实体主题background、非null owner的全局overlay/openingTitle、入口卡片Overlay和缺省/空白开幕标题。
- 不新增Mutation入口、GameInstance依赖、旧StoryDef播放或完成结算。

## Stop Conditions / Verification
遵守PROJECT-CONSTITUTION六项与U4总体预算；发现Effect顺序/准入规则冲突或需要白名单外改动时停止上报。运行新旧定向测试与`npx tsc --noEmit`；主Agent做联合架构/文档检查。
