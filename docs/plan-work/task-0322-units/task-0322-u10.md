## Constraints
- 每 owner 一条独立Player会话；source root Entry 与 terminal Story 分开。
- 读取投影不推进、不执行动作、不抽随机；正文逐条ack，input按token提交，点击次数沿用Player合同。
- 完成时先从会话表移除，再结算/发完成事件；关闭演出host至多一次。
- `StoryDef`按已裁定形状 `extends StoryNodeDocument`（含id/name/nodes/stages/extra）；不得读取旧`talklets`。
- 点击/选择的稳定提交标识允许 `choiceIndex` 或 optionId；token为末尾可选参数以保旧调用形式。
