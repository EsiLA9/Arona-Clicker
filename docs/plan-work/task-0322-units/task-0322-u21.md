# Unit 0322-U21：为新 StoryNode 演出事件补充显式 owner 与 run 路由信息

## Goal
扩展现有聊天演出事件以携带可选 owner/runId 和完整入口卡请求，并新增 `storyRunEnded` 生命周期通知；普通旧 Effect 不带来源时保持既有当前流行为。

## Constraints
- 旧 Effect 仍发无 owner/runId 事件，不能改变其当前面板语义。
- StoryNode 的 `owner:null` 表示全局流；非空owner表示目标学生流。
- `storyRunEnded` 必须携带 owner、runId、reason，供UI精确清理对应来源。
- `cardRequest`仅表达active card入口请求的作者载荷；不得以targetStoryId替代请求身份。
