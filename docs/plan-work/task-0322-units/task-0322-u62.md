# Unit 0322-U62：Story移动锁局部刷新

## Goal / Read Set

剧情开始或结束会改变全局移动门控，左栏 SYSTEM NOTE 与区域按钮必须跟随当前 Story session 状态。只刷新受影响的左侧区域；不重建 App，不破坏聊天中心、当前工作区、焦点或滚动状态。

核对 `controller-events.ts` 的 storyTriggered/storyRunEnded 事件时序、StoryService 完成/替换顺序、`rail.ts` 的移动锁投影与 `controller.refreshPanels(['left'])`。

## Allowed Files

- `src/ui/controller/controller-events.ts`
- `tests/ui/controller-story-movement-lock.test.ts`
- 本Unit及对应Receipt。

## Completion / Constraints / Verification

事件在当前同步结算栈结束后读取最终Story移动锁；完成结算可以重入启动尾巴，替换必须先安装新session，不得因旧run结束短暂解锁。只有锁状态实际变化才局部刷新左栏。真实Controller回归验证自动完成开幕正文后note与区域按钮解锁，且不调用整页render；替换重入验证没有中间解锁。
