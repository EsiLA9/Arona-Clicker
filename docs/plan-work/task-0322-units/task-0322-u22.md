# Unit 0322-U22：将 StoryNode Overlay 与 Presentation 接到具备来源生命周期的宿主

## Goal
新增StoryNode专用表现宿主，并让ActionHost把overlay/presentation命令委托给该宿主；提供来源级预检、执行、owner激活和run结束清理，旧ActionHost在未注入该端口时保留明确拒绝。

## Constraints
- 新宿主公开 `preflight(action,source)`、`execute(action,source)`、`close(source,reason)`、`activate(owner)`。
- options为 `{registry,eventBus,colorSystem,entityPresentation,getTitle(source)}`；不依赖GameInstance。
- 新StoryNode overlay/title事件携带owner与runId；卡片事件携带完整active `cardRequest`。
- 新host关闭时只清当前run的Overlay、标题、ephemeral主题与story表现，不清其他run。
- `getTitle(source)`提供openingTitle缺省来源；显式非空标题优先。
- state/travel/entry请求逻辑保持原样；动态准入仍在execute时按最新state核对。
