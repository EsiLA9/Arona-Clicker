# Unit 0322-U38：从TypeScript新Story内容重新生成Runtime Base JSON

## Goal

增加一个明确的本地同步命令，从已迁移的Base TypeScript Datapack源重新写出Runtime实际导入的 `base-pack/content.json`。

| 类型 | 路径 / 符号 | 读它的原因 |
| --- | --- | --- |
| 文档 | `docs/docs-829/03-data-structures/datapack-contracts.md` | Base包与Runtime导入边界 |
| 文档 | `docs/ai/context-packs/datapack-schema.md` 包装载行 | Base TypeScript源与bundle入口 |

| 脚本 | `scripts/export-base-datapack.mjs` | 现有包导出与Vite SSR装载方式 |

## Confirmed Facts

| 事实 | 依据（路径 / 符号） | 备注 |
| --- | --- | --- |
| Runtime的默认Datapack从`src/arona-clicker/content/base-pack/content.json`导入 | `default-datapack.ts` | 实际需替换的bundle |
| 正式Base内容由TypeScript `baseDatapackSource`组装 | `base-datapack-source.ts` | 不手工编辑生成JSON |
| `datapack:export-base`写到外部导出目录，且禁止输出到src | `scripts/export-base-datapack.mjs:assertOutputOutsideSource` | 需要单独安全的Runtime同步入口 |

## Constraints

- 从新TypeScript作者数据重建JSON；不把旧Talklet转译逻辑放入Runtime。
- 同步脚本只写唯一Runtime bundle路径，输出可读摘要并支持严格一致性复核。
- 不编辑`default-datapack.ts`入口、不写生成Schema、不改对外pack导出路径。

## Allowed Files

- `scripts/sync-base-datapack-bundle.mjs`（新增）

- `docs/plan-work/task-0322-units/task-0322-u38.md`
- `docs/plan-work/task-0322-units/receipts/receipt-0322-u38.md`

## Explicit Non-goals

- 不改base内容源、Story schema或加载流程。
- 不改版本兼容或外部Datapack包格式。

## Stop Conditions

1. 需要写白名单外路径。
2. 预计多于2个代码文件或500行净改动。
3. 需额外读取Read Set外超过2个文件。
4. 新TypeScript源无法生成与Runtime契约兼容的JSON。
5. 需要改变发布/资产处理路径或默认包加载。
6. 必需生成命令失败或生成结果无法解释。

## Completion Criteria

- [ ] `base-pack/content.json`由TypeScript新Story定义生成，不含生产旧`talklets`。
- [ ] Runtime bundle内的43篇Story与TS生产源ID/数量一致。
- [ ] 同步脚本不引入执行期旧格式编译器。
