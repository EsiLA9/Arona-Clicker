# Unit 0322-U20：为 StoryNode 演出提供按运行实例管理的主题与实体表现生命周期

## Goal

## Confirmed Facts
| 事实 | 依据（路径 / 符号） | 备注 |
| --- | --- | --- |
| `ColorSystem.runtimeTheme()`读取 `selectedRuntime`，而现有临时演出投影只跟踪一个 `temporaryThemeLayer/temporaryThemeId` | `color-system.ts:286` `syncSingleRuntimeTheme` | 多个新 run 不能只复用单槽字段 |
| 旧临时主题固定ID为 `story-ephemeral`，由 `clearStoryTheme` 单独清理 | `color-system.ts:403-437` | 新 run 使用独立身份，不受旧游标清槽 |
| `RuntimeThemeManager.pushEphemeral`支持同ID覆盖，`popEphemeral`按ID移除 | `theme-runtime.ts:265-282` | 由产品服务管理实际UI投影 |
| `setRuntimeOverride`以 target + owner 保存，并允许 story/area/init/manual 生命周期 | `entity-presentation-service.ts:121-153` | 新 story 清理需要run维度，避免误清其他运行实例 |
| `handleThemeEffect`写 area/student customTheme 时当前只复制 colorGroup/palette/tokens/nodes | `color-system.ts:405-427` | background 会被丢弃，需补齐 |

## Constraints
- StoryNode 临时图层使用独立 run 身份；旧 `clearStoryTheme()` 和旧 currentStory 游标只影响旧固定槽。
- `activate(owner)` 切换可见 StoryNode owner 时，临时主题必须只从匹配 owner 的 run 选择；run 关闭只清自己的资源。
- area/student 主题保持持久实体槽语义，复制完整 `ThemeEffectValue`，不得静默丢弃 `background`。
- story 生命周期实体覆盖按 `runId` 精确清理；manual/area/init 沿用现行领域策略。
- 只在本Unit列出的服务与测试中实现；EventBus、ActionHost 和 UI 由后续 Unit 接线。
