## Constraints

- 转换工具是一次性/开发期工具，不能由 Runtime、Datapack loader 或 `StoryBuilder` 导入。
- `convertSourceText(sourceText, fileName, options?)` 必须供其它任务复用，并返回诊断；未知modifier、无法解析引用或无效组合不能静默丢弃或猜值。
- 只输出实际的新 `nodes/stages` 数据，不保留旧Talklet作者对象。
- 状态效果批次映射到有序 `StoryAction.state.effects`；选择公共效果进入 `sharedActions`，选项自身效果进入该选项结果。
- 旧 `sendText` 映射为Button文案；仅旧实际回显的路径生成 `reply`。
- 静态总点击量恒为1的旧 `clickWork` 直接生成一个Click，并将回复/动作/转移放在该Click。
- 静态总点击量必定大于1的旧 `clickWork` 生成press工作量与第二个确认Click；随机结果可能跨过1与大于1时返回人工重写issue。

## Explicit Non-goals

- 不在本Unit改写正式作者源、定义factory、Schema、Registry引用或运行Bundle。
- 不执行或保留旧Talklet Runtime转换器。
- 只增加迁移器合同测试；不迁移既有Story运行时fixture。

## Stop Conditions

1. 需要修改白名单外文件或新增未列路径。
2. 转换器预计超过500行或需要超过3个实现/验证文件。
3. 需要读取Read Set外超过2个文件才能解释modifier。
4. 当前旧作者行为与Task合同/源码冲突。
5. 需要增加新动作原语、播放器能力或业务规则。
6. 必需的AST解析自检不可执行或失败且无法解释。

## Completion Criteria

- [ ] 导出 `convertSourceText(sourceText, fileName, options?)`，报告成功转换数、未转换/歧义及路径。

- [ ] CLI可对指定路径预览或明确`--write`；默认不写文件。
- [ ] 自动验证状态动作命名参数、选择共享/候选顺序、回复归属、单击边界和多击确认阶段。
