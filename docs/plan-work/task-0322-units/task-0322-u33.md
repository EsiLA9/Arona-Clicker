- 仅写新Story原语，禁止旧`line/narrate/TalkletBuilder`作者对象。
- 选择页的旧页效果迁为`sharedActions`，各选项效果与跳转归各自result。
- Plain display用auto；有效按钮/选择/卡片用明确input；多击需独立确认Click。
- ID与实际选项文本/动作保持，不能通过分页数组位置表达分支身份。
