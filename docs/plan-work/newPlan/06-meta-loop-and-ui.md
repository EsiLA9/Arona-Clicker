# Meta Loop 与空间化 UI

## 闭环

```text
经营 Spot
↓
提高产出 / 解锁库存
↓
获得商店货币
↓
购买招募票 / 碎片 / 礼物
↓
获得学生
↓
学生配置到 Spot
↓
改变 Spot 生产
↓
提高商店解锁效率
↓
触发学生剧情
```

## UI 原则

尽量呈现“空间”，而不是平铺系统入口：

```text
夏莱办公室
┌ 办公桌：Lv.12，+2.4K Credit/s
├ 通讯终端：招募、当前 Pick Up
├ 物资终端：今日库存 4/6
└ 休息区：白子正在这里，新消息 ●
```

玩家进入 Spot 后发现功能，Spot 才成为游戏的世界 UI。

## 完整样例：夏莱通讯终端

- Lv.1：解锁常驻招募。
- Lv.3：每日第一次招募折扣。
- Lv.5：解锁神名文字商店。
- 配置 Arona：通讯类 Spot +10%，每日商店额外出现一个商品。
- 完成 Arona 剧情：解锁特殊 Recruitment Ticket Offer。

建议用该样例跑通 Reveal → 商店 → 招募 → 重复 → 碎片 → 角色获得 → 剧情触发全链路，以验证 DSL 与 Datapack 的复用边界。
