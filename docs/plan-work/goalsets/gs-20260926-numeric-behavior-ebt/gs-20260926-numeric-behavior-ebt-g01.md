# G01：数值—行为系统实体与简化机会地图

## 对最终目标的贡献

建立能够跨生产、状态写入、事件响应、领域行为和读模型追踪的系统地图，使后续简化能针对重复责任或复杂边界，而不是仅凭相似命名合并机制。

## 完成定义

- [ ] 按流程列明定义、运行时索引/实例、权威状态、事件、派生视图和状态写入口。
- [ ] 标出资源生产、Spot/Shop 交易、抽卡、角色成长、剧情、Trigger/Affector、Visibility/Reveal/Milestone 等机制间的边界。
- [ ] 对每个候选简化列明保留语义、所需证据和不可直接合并的实体。
- [ ] 明确报告是静态源码调查，未执行测试的结论不能写成运行时验收结论。
