# Goal Set 模板

> 复制到 `docs/plan-work/goalsets/<set-id>/<set-id>-set.md`。它是可删除的讨论地图，不是当前事实源。

```markdown
# Goal Set：<最终目标名称>

Set ID：<gs-YYYYMMDD-简短主题>

## 最终玩家与作者体验

- 玩家最终能：<可观察的完整结果>
- 数据包作者最终能：<可声明、组合、验证的内容>
- 运行时权威事实：<预期归属；未核对则写“待核对”>

## 阶段全图

| Goal | 独立完成结果 | 前置依赖 | 当前 Draft / Task |
| --- | --- | --- | --- |
| G01 | ... | 无 | 待建立 |
| G02 | ... | G01 | 待建立 |

## 长期边界

- 明确暂缓：...
- 尚未裁定：...
- 终点不因首期能力收窄而自动改写；变化需在此说明原因。

## 下一步

- 当前讨论的 Goal：G01
- 会改变最近阶段方案的事实问题：...
```

阶段只写完成定义与依赖；最近阶段的语义在 Draft 展开。不要复制 Task 状态或验收结果。整个 set-id 目录应能直接删除。
