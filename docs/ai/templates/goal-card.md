# Goal Card 模板

> 复制到 `docs/plan-work/goalsets/<set-id>/<set-id>-g01.md`；文件名始终带 set-id。

```markdown
# G01：<阶段结果>

## 对最终目标的贡献

<这一阶段交付后，玩家或数据包作者新增的独立能力。>

## 完成定义

- [ ] <能独立验收的结果；不要写成函数或文件步骤>

## 依赖与边界

- 前置 Goal：...
- 本阶段明确暂缓：...

## 会改变方案的未知项

- 产品/架构待裁定：...
- 本地源码待核对：...

## 正式文档入口

- Draft：待建立
- Task：待建立
```

Goal Card 只为讨论导航；Draft 与 Task 应能在删除本卡后独立阅读。
