# 滚动 Draft 模板

> 复制到 `docs/plan-work/draft-<全局编号>-<主题>.md` 并登记 `00-index.md`。同一 Goal 的多轮 SolChat 讨论更新同一份 Draft。

```markdown
# Draft：<阶段目标>

状态：draft — <当前讨论进度>

## 目标与最终方向

<独立描述最终方向与本阶段结果；不依赖可删除的 Goal Set。>

## 本阶段玩法语义与边界

- 已裁定：...
- 明确暂缓：...

## 当前事实与待核对问题

| 问题 | 已核实依据 | 对方案/验收的影响 | 结论状态 |
| --- | --- | --- | --- |
| ... | 源码/测试路径，或“待核对” | ... | 已核实/待核对 |

## 裁定记录

| 待裁定问题 | SolChat 建议 | 本项目决定 | 依据/待验证项 |
| --- | --- | --- | --- |
| ... | ... | 采纳/修改/暂缓 | ... |

## Draft → Task 准入

- [ ] 语义和明确非目标已裁定
- [ ] 会改变方案的事实已核对
- [ ] 有独立完成定义及依赖关系
- [ ] 能给出施工 Read Set 与验收入口
- [ ] 已写明本阶段之后仍未完成的最终方向

## 下一步

<继续讨论、指定事实问题，或创建施工 Task。>

## 相关路由

<当前机制文档、相关 Task；不链接可删除的 Goal Card。>
```

建议、决定和已实现事实必须分列。不要将 Draft 的 `proposed` 状态当作已经授权施工。
