# 节点探索 UI Demo

独立实验，用于评估「从少数已知节点出发、沿连线逐步探索、进入独立子图并保留双方进度」的交互体验。

它不接入 AronaClicker 业务：不导入游戏模块及 Init / GlobalEnh / PlayerState / Runtime / Registry / Datapack / Effect，不读写存档，不使用 localStorage、sessionStorage、IndexedDB、Cookie 或 URL 参数。刷新页面即回到初始状态。

## 启动

```bash
npm run dev
```

打开根工具台（默认 `http://localhost:5173/`），点击「节点探索 Demo」卡片；也可直接访问同一服务下的 `/tools/node-graph-ui-demo/index.html`，端口以启动输出为准。

构建与预览：

```bash
npm run build
npx --no-install vite preview
```

产物入口是 `web-dist/tools/node-graph-ui-demo/index.html`，预览时同样从 `/tools/node-graph-ui-demo/index.html` 打开。

## 类型检查

```bash
npx --no-install tsc --noEmit -p tools/node-graph-ui-demo/tsconfig.json
```

该配置只包含本目录的 `app.ts`，`strict` + `noEmit`，不引入 Node 类型与游戏源码。

## 交互规则

| 状态 | 画布表现 | 可用动作 |
| --- | --- | --- |
| Hidden | 不生成任何节点与连线 | 无 |
| Frontier | 虚线圆、问号、「未知节点」 | 探索 → Known |
| Known | 完整名称、可读描述 | 取得 → Owned |
| Owned | 蓝色实心、勾选标记 | 查看信息；有子图时可进入 |

- 点击、Tab + Enter / Space 只负责选中；探索、取得、进入子图必须由面板按钮触发。
- 只有 Frontier 可探索、只有 Known 可取得；动作函数再次核对当前图、选中 ID 与状态，连点不会跳过阶段或重复结算。
- 普通链接双向揭示；单向链接只从起点沿箭头方向揭示；虚拟链接只表达关联，不参与揭示。取得后只把这些可通行链接直连的 Hidden 改为 Frontier，不降级、不递归揭示第二跳。
- 只有两端都非 Hidden 才绘制连线；Frontier 的可访问名称、面板文案与节点标签都不泄露真实名称或子图属性。
- 子图是完整独立画布，不是弹窗或并列视图；两张图各自保留状态与选中节点，顶栏面包屑可返回主图。
- 「重置 Demo」清空两张图进度、回到主图并选中 A。

## 预设星座与链接类型

主图提供 A–J 十个节点，形成多支交汇的星座网络；子图提供 X–Z、W、U、V 六个节点。新增节点仍沿现有逐步探索流程显现，不会一次性公开隐藏名称。

图例中的单向链接带箭头，只能从箭尾节点揭示箭头所指节点；母图概览按弱连通关系纳入单向边两端，箭头保留且线色更浅。虚拟链接使用浅棕色短虚线，只作关联提示，不提供探索方向，也不参与布局求解或母图连通范围计算；虚拟链接两端需要通过其它可通行链接分别发现后才显示。母图会保留范围内节点之间的虚拟线样式，但不会借它扩展节点范围。

## 母图概览

进入子图后，母图以只读拓扑概览显示。画布上方「母图节点上限」参数控制从共通入口开始、按弱连通关系逐层扩展时最多携带的节点总数，包含入口本身；虚拟边不扩展范围。增减节点上限只裁切 / 增加母图节点和连线，不重排或拟合已有坐标。概览保持母图原有 x/y 构图，以节点的 y 向偏移体现高度；不旋转平面，也不绘制母图网格、高度辅助线、背景板、边框或阴影。母图使用与子图相同的 viewBox、比例尺与相机平移，位置锚定在子图平面的固定逻辑坐标，不跟随入口节点拖拽；节点比例尺变化时以相同倍率缩放，不按当前内容范围调整大小。概览无事件、无 `tabindex`，不复制状态。

子图通过 `entryNodeId: 'X'` 显式标出共通入口，并沿现有 `childGraphId` 反查父图 D。D 与 X 保留各自图内 ID 和状态，但显示同一入口身份；跨层虚线曲线连接母图概览中的 D 与子图前景中的 X，不是一条可通行航道。

返回动作仍恢复母图完整视图、原有选择与探索状态。

## 空间投影与比例尺

保留现有二维 `solveLayout` 结果作为平面坐标，单一 `projectCoordinate` 再把 x/y 与 `elevation` 投到轴测屏幕坐标。参考平面以 viewBox 中心为缩放原点，网格随观察范围动态延展，不根据节点范围收边；网格每 5 格加深一次。画布上方「节点比例」滑杆和画布滚轮都可缩放平面网格与节点的 x/y 坐标，范围为 10%–1000%；滚轮以光标所在位置为缩放锚点。高度比例以 100% 为 1:1 基准，只按平面倍率变化量的 25% 响应：`1 + 0.25 × (scale - 1)`，因此 10% 时为 77.5%，1000% 时为 325%。

比例低于 100% 时节点本体和文字非线性缩小；缩放到 40% 及以下切换为单圆点、单字形和投影点，减少节点挤占观察范围。已知 / 已拥有节点显示短 ID，待探索节点仍只显示问号。可见节点之间另有一层浅色虚线连接其 z=0 平面投影，只属于当前子图的节点关系层，不会复制进母图星座。

正高度节点使用实线竖直辅助线，负高度使用虚线；两者均有平面椭圆脚点，零高度节点没有额外高度标记。脚点水平半径为节点本体半径的 80%，即本体约大 25%；节点本体比旧版本更小，透明点击范围不随视觉缩小。比例滑杆范围为 10%–1000%，重置回到 100%。当前 D / F / Z 抬起，E / W 下沉。

可直接拖动可见节点来调整其平面位置；拖动画布空白处会平移观察范围，使网格、节点、航道与高度辅助物一起移动。进入子图后，母图星座锚定在子图平面的固定逻辑坐标，随相机平移和比例尺以相同倍率移动，不随入口节点拖拽；增加或减少概览节点不会缩放 / 拟合母图构图，且不添加底板。节点位置、观察范围偏移与比例尺仅保存在当前页面会话，重置或刷新后恢复初始状态。

## 实现说明

- 文件：`index.html`（页面结构与 SVG 宿主）、`style.css`（局部样式与响应式）、`app.ts`（类型、固定数据、内存状态、动作与局部渲染）、`tsconfig.json`（独立严格检查）、本文件。
- 数据：`GRAPHS` 保存两张图的节点、边与两套固定坐标；`initialState` 与运行状态分离，`createSessionState()` 生成 `nodeStates` / `selectedNodeIds` / `currentGraphId`。初始化只对 Owned 邻居做一次 Hidden → Frontier 揭示。
- 渲染：内联 SVG 在共享观察层中按参考网格、平面投影虚线、真实航道、高度辅助层、节点层顺序绘制；普通状态动作保留 DOM。比例滑杆更新平面缩放、可见节点、脚点 / 高度线、投影线、航道端点和跨层曲线，不重建拓扑。
- 母图概览：全画布只读 `<svg>` 与子图共用 viewBox；按弱连通关系绘制入口局部拓扑，不附加底板；保留母图原 x/y 构图，以 y 向偏移体现高度，不按内容范围拟合；比例尺与相机变换和子图完全相同。跨层曲线单独处于两张 SVG 之上，端点按共享宿主坐标从实际节点位置读取。
- 拖拽：节点 `pointer` 事件把屏幕位移逆投影为 x/y 平面位移；画布空白处的拖动则只更新共享观察层偏移，让平面与节点同步平移。两种偏移都仅保存在当前页面会话。
- 响应式：画布容器宽度小于 560px 时切换到紧凑坐标与 `420×520` viewBox，桌面使用 `760×510`；切换只重建当前图内部并在必要时恢复节点焦点。点击目标为 `node__hit` 透明圆，375px 视口下约 64×64 CSS px。
- 可访问性：节点 `role="button"` + `tabindex="0"`，`aria-label` 只描述当前可知信息；`focus-visible` 显示虚线外环；动作切换后焦点依次落到「取得」「进入子图」或选中节点，不落到已移除元素。
- 过渡只作用于颜色与透明度，并在 `prefers-reduced-motion: reduce` 下取消。

## 实际验收（2026-10-20）

环境：Windows 桌面；Edge 现有 Demo 标签页；Vite 5.4.21。

- 定向 TypeScript 检查：通过。
- `npm run build`：通过，Demo 入口与独立 chunk 正常产出；Vite 提示已有 game chunk 超过 500 kB。
- 初始页面：母图以 `1 / 1 / 1` 启动；空间比例滑杆默认 100%，配置范围为 10%–1000%。
- 固定参考系：早期比例交互验收记录了网格保持不变、控件范围为 85%–115%；后续裁定已改为网格随平面坐标缩放，当前范围为 10%–1000%，旧记录不代表当前行为。
- 尺寸关系：桌面节点本体半径为二维布局半径的 75%，脚点水平半径为 60%，视觉本体约比脚点大 25%；透明点击半径保留原尺寸。
- 页面截图检查：当前缩略图仅保留母图可见节点与连接；母图平面 / 高度辅助图形未复制到背景；缩放滑杆与图例同排可见。
- 主图交互：在 Edge 中从 B 开始取得并逐步显现 C / D / E / F，最终计数为 `6 / 0 / 0`；D / F 抬起，E 下沉。将高度幅度调低后 E / F 中心距离 59.8 viewBox 单位，大于 48 的节点本体直径。

## 已知限制

- 只有两张固定图与固定坐标；节点位置与观察范围仅支持当前会话内调整，尚无持久化或独立相机控制。
- 演示数据直接写在脚本中，界面不泄露隐藏信息并不等于数据加密。
- 没有持久化，也没有节点编辑器或数值效果；这些都不在本 Demo 的验证目标内。
