# roadmap-0012 — 平级表现目标与统一图层编辑器

> 本文记录将表现层从“按背景/区域分类”重构为“按表现目标平级管理”的任务；运行时安全规则以源码与 roadmap-0011 为准。

## 目标

把全局背景、栏位、区域、Tab、按钮、卡片、气泡和弹窗等可装饰对象统一视为表现目标。表现层编辑器只维护一套图层编辑器，通过级别筛选弹窗加入尚未配置的目标。

## 交互约定

- 表现目标在列表中平级展示，不按父子树嵌套编辑；
- 每个目标显示名称、级别、父级路径和继承状态；
- “加入个性化表现目标”弹窗先筛选级别，再选择尚未配置的目标；
- 选中目标后创建默认空图层并立即展开；
- 全局背景保留系统颜色层；其他目标不复制系统颜色层；
- 所有目标复用同一套空/纯色/渐变/图片图层编辑器。

## 目标注册表

目标注册表由 TypeScript 维护，不以 CSS 组合选择器推断目标：

| 级别 | 示例目标 | 父级 |
| --- | --- | --- |
| global | 全局背景 | — |
| cluster | 整体外壳、顶部栏、左侧栏、中部栏、右侧栏、底部栏 | global / shell |
| region | 左侧栏·区域、左侧栏·通讯录、左侧栏·故事、中部栏·聊天、右侧栏·设施 | 对应簇 |
| control | 顶部按钮、Tab、普通按钮、卡片、聊天气泡 | 对应簇或区域 |

每个目标具有稳定 ID、中文名、级别、父级、目标类型和是否允许用户配置。

## 数据结构

继续使用 `PresentationHostDef` 作为新目标的存储单元：

```ts
interface PresentationHostDef {
  id: string;
  parent?: string;
  layers?: BackgroundLayerDef[];
  layerOrder?: string[];
  systemColorLayerIgnored?: boolean;
}
```

旧的 `presentation.layers` 按 `region` 的数据继续读取，不立即迁移；编辑器展示时映射为对应目标，新的用户编辑优先写入 `presentation.hosts`。

## 任务切片

### T0：目标注册表

- 建立内置表现目标清单；
- 统一目标 ID、中文名称、级别与父级路径；
- 为未接入渲染的目标保留注册状态，避免提前产生无效样式。

当前进度：已完成首版内置目标注册表，覆盖全局、簇、区域和常用控件目标。

### T1：平级编辑器模型

- 将表现层 UI 改为目标列表；
- 每个目标使用统一图层卡片；
- 显示目标来源、继承关系和配置状态；
- 移除顶部系统颜色层遗留物。

当前进度：已完成首版平级目标摘要与统一表现层栏目；现有图层编辑能力继续复用。

### T2：目标选择弹窗

- 增加“加入个性化表现目标”；
- 支持 global / cluster / region / control 级别筛选；
- 隐藏已配置目标；
- 选择后创建默认空图层并进入编辑状态。

当前进度：已完成四级筛选弹窗；旧的全局/区域插入入口已移除，选择区域目标会创建默认空图层，控件目标写入统一宿主结构。

### T3：统一目标解析

- 目标按 parent 链继承；
- 合并全局、父级和自身图层；
- 仅全局目标注入系统颜色层；
- 处理排序、空层、透明度和安全值；
- 输出只读目标表现视图。

### T4：渲染接入

- 面板、栏位、Tab、按钮、卡片、气泡和弹窗按目标 ID 读取背景；
- 无配置目标继续回退到父级或全局背景；
- 内容层始终位于图层之上。

### T5：验证与清理

- 测试目标筛选、重复屏蔽、默认空层、继承和排序；
- Edge 验证目标添加、删除、折叠、实时预览和重新打开；
- 清理旧的“区域表现层”专用编辑逻辑；
- 更新 roadmap-0011 与本任务状态。

## 验收标准

- 表现层栏目下所有目标平级显示；
- 新增目标必须通过级别筛选弹窗；
- 已配置目标不会重复出现在候选列表；
- 任意目标使用同一套图层编辑器；
- 空目标不会产生视觉内容；
- 目标未配置时正确继承父级；
- 全局系统颜色层只出现一次且可忽略/排序；
- 类型检查、专项测试和 Edge 视觉验证通过。
