# roadmap-0011 — 控件背景图层服务

> 本文记录将统一表现层能力扩展到大部分 UI 控件背景的施工计划；具体字段与运行时行为以当前源码为准。

## 目标

让面板、栏位、按钮、Tab、卡片、聊天气泡和弹窗等 UI 宿主可以使用统一的背景表现层。每个宿主可拥有多层颜色、渐变或图片，并支持透明度、定位、尺寸、混合模式、显示状态与父级继承。

## 非目标

- 不把任意 CSS 属性开放给用户输入；
- 不允许图层覆盖文字、SVG 和交互内容层；
- 不在 UI 组件中直接写入 PlayerState；
- 不为旧存档编写迁移逻辑；
- 不立即替换所有历史硬编码装饰，先建立安全的统一出口。

## 设计约束

1. 所有主题原始数据由 `UserThemeService` 管理，UI 只编辑 draft。
2. 所有继承、默认值、系统层注入、空层过滤和顺序解析在 TypeScript 服务侧完成。
3. 编辑器顶部图层是视觉最前层，运行时通过明确的 `z-index` 保证编辑顺序与绘制顺序一致。
4. 系统颜色层始终存在，可被忽略但不可移除；用户图层可插入、删除、折叠和排序。
5. 组件背景与内容采用独立 DOM 层，背景层不得改变内容层的点击、文字和 SVG 可读性。

## 目标数据流

```text
UserThemeDraft
  → UserThemeService / ThemeRuntime
  → ComponentLayerResolver
  → ResolvedComponentPresentation
  → UI presentation renderer
  → background layers + content layer
```

## 施工切片

### C0：宿主与字段盘点

- 建立 UI 宿主注册表：全局背景、三栏面板、顶部/底部栏、Tab、按钮、卡片、聊天气泡、弹窗。
- 标明每个宿主的 CSS 根节点、父簇、内容层和现有硬编码背景。
- 统一宿主 ID 与父级继承路径，避免使用脆弱的组合 class 判断。

### C1：组件图层数据契约

- 为组件簇增加可选图层列表、图层顺序和系统层忽略标记。
- 复用现有 `BackgroundLayerDef` 的安全字段，补充组件作用域与状态条件。
- 明确 `empty`、`solid`、`gradient`、`image` 四种表现类型的参数集合。
- 同步 schema 与编辑器元数据，并补充结构校验。

### C2：统一解析服务

- 新增组件图层解析入口，输入主题草稿/运行时主题与宿主上下文。
- 实现宿主 → 父簇 → 全局背景的继承链。
- 注入系统颜色层，处理忽略状态与图层排序。
- 过滤空图层，限制资源引用和颜色/渐变值范围。
- 输出只读解析结果，禁止 UI 直接拼装继承后的样式。

当前进度：已提供宿主只读视图入口，支持安全值解析与显式宿主图层顺序；父宿主继承和系统层注入仍待后续切片。

### C3：统一渲染出口

- 抽出背景层 DOM 渲染器，统一生成定位、尺寸、透明度、混合模式和 `z-index`。
- 为面板、Tab、按钮、卡片、气泡和弹窗增加独立背景容器。
- 内容节点统一置于背景层之上，确保文字与 SVG 继承同一套前景色判定。
- 处理 `pointer-events`、圆角裁切、隔离堆叠上下文和响应式尺寸。

当前进度：三栏面板已通过宿主 ID 读取背景图层；无宿主配置时回退到全局背景。

### C4：编辑器扩展

- 按宿主/簇分组显示图层列表。
- 支持折叠、插入、删除、忽略系统层、上移/下移和实时预览。
- 按表现类型动态显示参数表单。
- 为图片资源提供 Navi，为定位和尺寸提供受控选项。
- 显示“继承自父簇”“系统层”“用户覆盖”等来源信息。

### C5：分批接入控件

接入顺序：

1. 左、中、右三个面板；
2. 顶部栏、底部栏与栏位装饰线；
3. Tab、Switch、普通按钮和 active 状态；
4. 卡片、信息块和运营设施；
5. 聊天气泡、输入区和剧情导航；
6. 弹窗与特殊展示组件。

每批接入都保留未配置时的现有默认视觉，并允许通过父簇继承获得统一背景。

### C6：验证与清理

- 增加图层顺序、继承、空层、系统层忽略和类型切换测试。
- 在 Edge 中验证浅色/深色接口、透明背景、图片资源、active 状态和滚动容器。
- 清理已被统一服务替代的局部硬编码背景。
- 更新主题、UI 模块文档与本路线状态。

## 验收标准

- 任一已接入宿主可显示 0 至多层背景图层；
- 编辑器顶部图层在视觉上始终最前；
- 未设置子簇时正确继承父簇，子簇覆盖只影响自身；
- 系统颜色层无法删除但可忽略和排序；
- 图层不拦截内容交互，正文和 SVG 保持可读；
- 主题切换、实时预览、保存与重新打开后顺序一致；
- `npx tsc --noEmit`、专项测试和 Edge 视觉检查通过。
