# Roadmap 0007：强化揭示与服务权限语义

> 本计划记录 GlobalEnhancement 的信息揭示、资源观察与服务能力解锁之间的边界问题；具体机制仍以源码与测试为准。

## 问题

- 未观察过青辉石时，依赖 0 青辉石成本的服务可能被错误判定为“尚不可见”。
- “资源是否已观察”不应成为免费服务可见性或购买性的隐式前置条件。
- 主题编辑权限由 GlobalEnh 提供的 `user-theme.editor` 能力暂时免费赠送，不声明任何价格条目。

## 当前临时决策

- `base:enhancement:user-theme-editor` 不声明 `price`，以真正的无价格条目表达免费。
- 暂不通过观察青辉石自动赠送或自动激活主题编辑权限，仍由 GlobalEnh 购买动作激活。
- 未观察青辉石时的揭示/可见性异常列入后续修复，不在本次临时免费调整中扩展范围。

## 后续切片

- [ ] 复现未观察青辉石时的 GlobalEnh 可见性与 `NotVisible` 路径。
- [ ] 分离资源观察状态、强化揭示状态、资源支付判定和服务能力状态。
- [ ] 增加无价格 GlobalEnh 在未观察对应资源时仍可见、可购买的回归测试。
- [ ] 复核其他免费服务，避免把资源价格字段误当作资源观察门槛。
