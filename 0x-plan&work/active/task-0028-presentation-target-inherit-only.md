# 任务 0028：新建表现目标保持默认外观

> 状态：✅ 已完成（2026-09-07）
> 范围：游戏内用户自定义主题编辑器、表现目标宿主创建、背景回退与状态表现。

## 1. 目标

让用户在编辑器中新增一个表现目标后，在尚未实际编辑任何表现属性前，游戏内控件保持与“未创建该表现目标”完全一致的外观。

## 2. 根因

当前选择表现目标时会立即插入一个 `empty` 透明占位图层。运行时会把它识别为已配置的表现层，并进入宿主系统颜色层合成路径；未创建宿主的控件则走无宿主的基础背景回退路径，因此两者颜色可能不同。

`empty` 图层表示“明确存在一个透明表现层”，不等同于“尚未配置表现层”。

## 3. 施工清单

- [x] 新增表现目标时只创建宿主元数据，不插入透明占位图层。
- [x] 保持空 `layers` 宿主继续沿用默认 / inactive / active 的原有回退结果。
- [x] 保证用户点击“插入新图层”后仍能正常创建第一层表现。
- [x] 增加无宿主与空宿主的背景结果一致性测试，覆盖 inactive 与 active。
- [x] 更新相关机制文档和任务索引。
- [x] 运行专项测试、类型检查和差异检查。

## 4. 期望效果

| 操作 | 期望结果 |
| --- | --- |
| 不创建表现目标 | 控件使用原有默认表现 |
| 新建表现目标但不编辑 | 控件外观不发生变化 |
| 只修改形状 | 只改变形状，背景来源仍保持默认回退 |
| 插入第一层用户图层 | 从此开始产生用户自定义背景覆盖 |
| 编辑器取消 / 删除目标 | 恢复未创建目标时的外观 |

## 5. 验收标准

- 新建宿主的 `layers` 为空，不再生成透明 `empty` 占位层。
- 空宿主与无宿主在 inactive、active 状态下解析出的背景值一致。
- 新建宿主后仍可通过“插入新图层”添加纯色、渐变或图片层。
- `npx vitest run` 相关专项测试通过。
- `npx tsc --noEmit` 通过。
