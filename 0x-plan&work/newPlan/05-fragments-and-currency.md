# 碎片、确定性获取与货币

## 碎片路线

```text
Gacha：快，但随机
碎片商店：慢，但确定
剧情赠送：条件明确
世界线奖励：与经营绑定
```

示例：未拥有白子时，`40 Shiroko Eleph → 解锁 Shiroko Normal`。这能避免随机性长期封锁聊天、好感、羁绊剧情、Spot 配置等内容入口。

## MVP 货币策略

建议先只保留少数有清晰职责的资源：

| 资源 | 职责 |
| --- | --- |
| 信用点 | 普通经营货币 |
| 青辉石 | 招募 / Global 资源 |
| 角色 Eleph | 角色长期培养与确定性获取 |
| World Token | 当前 Init 的特殊经营成果 |

避免同时出现神名文字、神名精髓、Variant 碎片、通用碎片、招募点等大量同质货币。

## World Token

本世界线经营与里程碑产出 World Token；重启时信用点和 Spot 清空，World Token 按规则保留或结算；World Shop 可提供永久强化、Variant 碎片、ColorGroup 或新 Init。

World Token 的关键价值是让“何时重启”成为经济决策，而非单纯清空进度。
