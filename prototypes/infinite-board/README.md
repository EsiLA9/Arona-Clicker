# Infinite Board 原型

独立纯前端二维图板实验。只依赖浏览器 API 和仓库已有的 Vite / TypeScript，不导入 AronaClicker 运行时代码，也不读取或修改游戏存档。

## 启动

```bash
npm run dev
```

在本地工具台打开「Infinite Board 原型」，或访问 `/prototypes/infinite-board/index.html`。生产构建入口为 `web-dist/prototypes/infinite-board/index.html`。

独立类型检查：

```bash
npx --no-install tsc --noEmit -p prototypes/infinite-board/tsconfig.json
```

## 使用

- 空白处右键可添加数据源、处理节点或结果节点；元素右键编辑、复制、开始连接或删除。元素的语义类型决定连接能力，视觉样式可以独立编辑。
- 双击节点标题或描述可在原文字位置快速编辑；双击连线可在连线中央编辑名称。输入框失焦或按 Enter 保存，Escape 取消；描述使用 Ctrl+Enter 保存并允许 Enter 换行。属性右键菜单仍可编辑类型等其他字段。
- 左键在画布空白处拖出矩形选区，可多选节点；拖动已选节点会一起移动，Delete / Backspace 删除整组及关联连线。拖动单个元素内部移动，拖非交互点的四边或角落调整尺寸；Output / Input 始终优先处理连线。
- 当前关系规则为「数据源·数据 → 处理节点·数据」和「处理节点·结果 → 结果节点·结果」。从 Output 拖线时，所有兼容目标及其 Input 以绿色提示；悬停目标后突出具体落点，不兼容的节点以红色提示。拖到兼容目标本体后松开会使用其唯一 Input，拖到 Input 则明确记录该作用点。右键元素选择“开始连接”后，点击目标本体或 Input 也可创建连接。
- 拖动已存在的 Edge：在靠近起始端处按下会转移来源端，靠近箭头末端处按下会转移目标端；目标未命中元素时，被拖端跟随鼠标，命中元素本体或对应 Output / Input 时预览吸附并可转移。拖到空白处松开会询问是否删除 Edge。
- 按住中键并拖动即可平移画布，也兼容中键按住后再加按左键；滚轮以指针为锚点缩放；点击右下角倍率恢复 100%。
- 右键连线可以编辑名称、视觉类型或删除。选中后按 Delete / Backspace 删除；Escape 取消连接或当前拖动。
- “导出 JSON”保存整个 Board；“导入 JSON”会检查 schema 版本、字段、ID、端点、重复边和自连接。
- 图板自动写入本地浏览器 `localStorage`。清空前会要求确认。

## 手工验收清单

- [ ] 任意方向平移，能在正负坐标放置元素；指针锚点缩放范围为 30%–250%，网格与元素保持对齐。
- [ ] 拖动元素、缩放元素后刷新页面，位置和尺寸仍按 24px 网格单位保存。
- [ ] 左键空白处拖出选区确认多选；拖动其中一个节点时整组选中节点一起移动，Delete 删除整组；中键单独拖动及中键加左键拖动都能平移画布，单独左键拖动空白处不会平移。
- [ ] 从四边和四角分别缩放，确认交互点不会触发尺寸变化，内部拖动仍只移动元素。
- [ ] 添加、编辑、复制、删除元素；复制拥有新 ID 且错开两格，删除时相关连线一并清理。
- [ ] 双击节点标题、描述和 Edge，确认文字原位进入快速编辑；验证 Enter / 失焦保存、Escape 取消，同时普通点击仍可选中、拖动仍可移动节点或转移 Edge。
- [ ] 创建符合类型规则的关系；确认不兼容目标不会被高亮，自连接和重复有向边被拒绝；移动和缩放节点时边端点跟随。
- [ ] 从数据源 Output 拉线，只有处理节点的「数据」输入高亮；从处理节点 Output 拉线，只有结果节点的「结果」输入高亮。
- [ ] 拖到兼容目标本体时连接到其唯一 Input，拖到该 Input 时记录具体作用点；不兼容目标显示红色提示。
- [ ] 空白处松开取消；自连接和重复有向关系被拒绝；移动或缩放节点后边仍从正确的交互点/元素边界出发并指向目标。
- [ ] 分别从 Edge 两端附近拖动，确认选择的来源端/目标端正确；拖到其他元素本体或对应交互点转移端点，拖到空白处确认/取消删除。
- [ ] 选中、编辑和删除连线；确认箭头指向目标元素，并在松到 Input 时落在该交互点。
- [ ] 导出后清空并重新导入；刷新后节点、连线和视图恢复。
- [ ] 导入错误 schema、缺失端点、重复 ID 的 JSON 时显示错误并保留当前图板。
- [ ] 使用 100 个节点、150 条连线操作平移、缩放、拖动与选择。

## 已实现与未实现

已实现：无限视口、世界/屏幕坐标、网格吸附、缩放锚点、元素 CRUD、元素语义类型与端口兼容规则、拖动时兼容目标高亮、三种视觉类型区分、尺寸调整、有向 Edge、边编辑、删除级联、JSON 导入导出、本地持久化和键盘删除。旧版 schemaVersion 1 图板会迁移为仅允许旧版元素彼此连接的类型。

轻量性能处理：相机平移 / 缩放通过整层变换完成；指针更新按帧合并；移动和缩放节点只刷新自身及相邻 Edge；连线查重使用索引；滚轮停止后合并保存。

未实现：自动排布、避障、旋转、Group、业务语义、运行时集成、后端、多用户、视口虚拟化 / 裁剪和 Canvas 批量 Edge 渲染。
