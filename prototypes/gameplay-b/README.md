# Gameplay B 独立原型

这是一个独立运行的玩法 B 预研原型。页面、规则、路线、内容和测试都由本目录维护，不导入 AC 源码、配置、内容、存档或资源。

## 启动与检查

在本目录执行：

```sh
npm ci
npm test -- tests/calibration.test.ts
npm test -- tests/park-demo.test.ts
npm test
npm run typecheck
npm run build
npm run dev
```

开发服务器固定使用 `http://127.0.0.1:5174/`，与根目录本地工具台的 5173 端口并行运行。启动原型服务后，可从本地工具台的“玩法 B 预研”卡片新开页面。打开页面后只需 Click 推进当前场所活动或整轮战斗；没有实时计时或速度要求。刷新页面会以固定 demo seed `park-inspection-demo` 重新开局。

| 02 | 林荫连廊 | 寻找轮迹与代币线索，活动度 2 |
| 03 | 游园服务亭 | 休息并按个人结果恢复，活动度 1 |
| 04 | 代币电玩馆 | 搜索通往游乐设施的线索，活动度 1 |

| 07 | 镜面迷宫 | 按 DEF 检定前进，活动度 2 |
| 08 | 摩天轮检修廊 | 按 ATK 检定记录线索，活动度 1 |
| 09 | 烟花排练广场 | 临时领头、冲撞者与烟花手战斗 |

开局队伍是 2 名前排与 2 名后排。节点 6 加入千世后为 5 人，节点 10 加入玲奈后为 6 人；入队和自动转场不另占 Click。活动总计 10 次 Click，出口交接 1 次。

## Click 与战斗规则

- 一次 Click 结算当前场所的一次全队活动，或当前已冻结的一轮战斗。活动完成或战斗获胜后可自动进入下一个节点，但该 Click 不会继续执行新节点行为。
- 每名 Chara 每轮至多打出一张普通技能卡；随机触发的技能是免费额外行动。普通技能消耗角色自己的 sCost；它在同一场战斗的回合间保留，跨战斗重置。观察/待机额外恢复 sCost。
- 我方与敌方行动在同一 Click 汇总结算。该轮伤害与已准备治疗按净 HP 变化处理，因此治疗可以抵消致命伤。活动结算后若全队 HP 为 0，路线立即失败。
- 首版三种卡牌配方：敌冲锋 + 同目标我方掩护，冲锋伤害 -1 且保留 2 点护盾；敌掩护 + 同目标我方狙击，先拆 2 点盾再攻击一次；我方冲锋 + 另一名 Chara 掩护，冲锋攻击 +1 且冲锋者获得 1 点盾。
- 纺希的“校准镜”只给本次已准备的普通狙击 +1，不额外生成卡牌或攻击。

敌方意图循环、活动检定细节、Boss 和烟花手行为及营地数值是当前原型候选，便于体验与复核；它们不代表用户已经逐条确认。用户明确确认的队形、Click 边界、三种基础配方与同轮治疗结算保持为确认规则。

## 已实测的完整回放

正式入口固定使用 seed `park-inspection-demo`。同一 seed 的 Route Runtime 回放两次得到相同路线事件、战斗轮数与结局。

| 项目 | 实测结果 |
| --- | --- |
| 结局与路线 | 胜利；节点 01 至 12 均进入；6 名队员到达出口 |
| 节点 05 / 09 / 11 战斗轮数 | 4 / 5 / 6，共 15 轮 |
| 非战斗 Click | 11 次：10 次活动 + 1 次出口交接 |
| 总 Click | 26 次；无单独移动、招募或转场 Click |
| 节点 09 意图 | 烟花手第 2 轮装填为无目标 no-op；领头第 1 轮实际受伤后，第 2 轮优先冲锋 |
| 节点 11 意图 | 第 3 轮烟花齐放目标为 4 名前排与最低 HP 的存活后排纺希；每个目标固定受伤 1 |
| 营地 | 节点 06 使节点 09 入场 sCost 为 3；节点 10 使 Boss 战从第 2 轮起获得额外回复 |
| 浏览器 | 2026-10-03，Codex In-app Browser，`http://127.0.0.1:5173/`；实走至节点 12 并看到 complete 终态。无可见错误覆盖层；当前浏览器操作接口不提供 DevTools Console 读取，因此 Console 未独立采集 |

自动回归另覆盖单 Click 失败与同轮互相击倒平局；两种夹具使用极小战斗配置，验证终态、结果事件与终态重复 Click 幂等。失败/平局夹具由 Runtime 测试执行，不是页面上的可选模式。
