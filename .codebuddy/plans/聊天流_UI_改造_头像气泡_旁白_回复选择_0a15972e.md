## 产品概述

对 AronaClicker 中栏聊天流（`src/ui/components/center-panel.ts` 驱动的 talklet 演出）进行 UI 改造，参照 `closureTalkPart/` 下 Closure Talk 示例的 html/css 风格：NPC 对话呈现"圆形头像 + 用户名 + 带小箭头的聊天气泡"，玩家回复为右侧亮蓝气泡，支持"场间旁白"（居中/靠左/靠右三种对齐），并将选项列表升级为新型"回复选择"卡片。改造前先完成项目预览与策划。

## 核心功能

- **可选圆形头像**：NPC 气泡左侧渲染圆形头像（`border-radius:50%`），支持数据包提供头像 URL；未提供时回退为首字母圆形占位，实现"可选圆形渲染"
- **用户名 + 小箭头聊天气泡**：NPC 消息为左侧蓝灰气泡（左箭头指向头像），玩家消息为右侧亮蓝气泡（右箭头），气泡上带用户名，`width:fit-content`
- **场间旁白**：新增 narration 类型的 talklet，横跨聊天流宽度、居中对齐为默认；兼容 left / right 对齐模式
- **新型回复选择**：选项从扁平按钮升级为白底圆角卡片（标题栏 + 竖条装饰 + 居中选项列表），保留现有 `data-story-choice` 交互契约与 LOCKED 态
- **兼容性**：所有新增字段可选、向后兼容；不改动引擎推进逻辑（旁白仍按普通 talklet 推进），UI 只读 `getView()`

## 技术栈

- 现有技术栈不变：TypeScript + Vite + vitest；UI 为 TS 模板字符串渲染 + 原生 CSS（无组件框架，不引入新依赖）
- 数据层仍走 Datapack 声明式：新增字段通过 Talklet 可选属性表达，并同步 Schema 协议

## 实现方案

### 数据层扩展（声明式、向后兼容）

在 `src/engine/types/entities.ts` 的 `Talklet` 增加三个可选字段（带 `@label` TSDoc）：

- `kind?: 'talk' | 'narration'`（缺省 `'talk'`，旧数据不受影响）
- `align?: 'center' | 'left' | 'right'`（缺省 `'center'`，仅 narration 生效）
- `avatar?: string`（可选头像 URL/资源路径，缺省渲染首字母圆形占位）

`Talklet` 位于 `scripts/gen-engine-schema.mjs` 的 `HAND_TYPES` 清单，编辑器表字段手写在 `tools/datapack-editor/schema/editor-extras.ts` 的 `storiesTable()` 中——必须同步在 `talklet` object fields 中追加 `kind/align/avatar`（带中文标签），再执行 `npm run gen:schema` 重新生成 `engine-defs.gen.json`，通过 `engine-schema.sync.test.ts` 三向一致校验。

### 渲染层重构（story.ts 为核心）

- `ChatEntry` 的 `kind` 扩展为 `'talk' | 'narration' | 'system'`，新增可选 `align?`、`avatar?` 字段（`isPlayer`/`storyType` 保留）
- 重写 `renderChatHistory`：按条目分支渲染——narration 输出对齐型旁白块（center 居中 / left 左对齐 / right 右对齐，横跨全宽）；NPC talk 输出"圆形头像 + 名字 + 左箭头气泡"；玩家 talk 输出"右侧右箭头亮蓝气泡"；system 保留轻量居中虚线样式
- 重写 `renderCurrentStory`：对话气泡复用同一套 talklet 渲染逻辑；`choices` 存在时渲染"回复选择"卡片（header 标题 + 竖条装饰 + 白底居中选项，LOCKED 态保留）；无 choices 时保留"继续"按钮
- 头像渲染：`avatar` 有值输出 `<img>`（`object-fit:cover` 圆形裁切），无值输出首字符圆形占位（统一底色，避免 broken image）
- `src/ui/controller.ts`：`appendStoryPages` 将 `story.page` 的 `kind/align/avatar` 透传到 ChatEntry；玩家回复（`clickSend`）仍以 `isPlayer` 标识
- `src/ui/components/center-panel.ts`：`renderSendButton` 保留 `data-send` 交互与 idle/advance/work(clickWork 进度条)/choice 分支，仅视觉类名与底部按钮样式微调统一；`renderChatLauncher` 保留

### 样式（styles.css）

沿用现有 CSS 变量体系（`--cyan:#3b9eff`、`--lime:#2ec494`、`--ink:#1e2a38`），新增 yuzu 风格类：`.chat-avatar`（圆形、尺寸适配中栏宽度约 44-52px）、`.chat-talk-npc`/`.chat-talk-player`（气泡底色 `#4c5b70`/`#4a8aca` + `::before` 三角箭头）、`.chat-narration`（center/left/right 三对齐）、`.reply-card`（白底圆角卡片 + header 蓝竖条 `#3493f9`）。沿用现有滚动捕获/恢复机制，不改 `.chat-stream` 结构与交互。

## 架构设计

```
UIController(controller.ts) → pushChat/appendStoryPages → ChatEntry[]
        ↓ 透传 kind/align/avatar/isPlayer
renderChatHistory / renderCurrentStory (story.ts)
        ↓ 输出 HTML 字符串
center-panel.ts renderChatTab（chat-stream + sendButton）
        ↓
styles.css（yuzu 风格视觉层）
```

- 分层不变：引擎（只读 getView）→ 控制器（累积聊天流）→ 渲染（纯字符串）→ 样式
- 不改引擎推进逻辑、不改 StateMutationService、不改数据包内容；新字段全部可选，旧 datapack 零迁移

## 设计风格

参照 Closure Talk 的 yuzu 聊天演出风格，融合 AronaClicker 现有蓝色系设计语言：整体为清爽明亮的"游戏内聊天"质感。

- 聊天区背景延续现有浅蓝渐变（`#e9f3ff` 系），气泡使用参考样例的蓝灰 `#4c5b70`（NPC）与亮蓝 `#4a8aca`（玩家），对比清晰、层次分明
- 头像为纯圆形容器（`border-radius:50%`），有图时 `object-fit:cover` 裁切，无图时首字母圆形占位（浅色底 + 品牌蓝文字），保持一致性
- 气泡采用参考样例的 `width:fit-content` + 5px 三角小箭头（NPC 左指向、玩家右指向），贴近社交聊天 App 的亲切感
- 场间旁白横跨全宽、居中为默认，靠左/靠右模式通过对齐类兼容；文字加粗深蓝灰（`#4c5b70`），在气泡流中形成"呼吸感"停顿
- 回复选择为白底圆角卡片（`#f3f7f8` 底 + `#d8d8d8` 边框），header 带 `#3493f9` 竖条装饰与"回复"标题，选项白底居中、hover 轻微高亮，LOCKED 态半透明禁用
- 微交互：气泡 hover 轻微上浮阴影、回复选项 hover 边框变蓝，全部尊重 `prefers-reduced-motion`
