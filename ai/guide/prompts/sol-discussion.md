# 外部方案讨论提示词

> 用于讨论需求、方案和实施顺序。填写已有 Task 与核实过的事实；外部 AI 的输出是建议，由本项目结合源码、测试和用户要求判断。

```text
请讨论以下需求，先说明玩家或内容作者可观察到的预期结果，再分析可行方案、依赖和必要的实施步骤。

需求：<需求>
相关 Task 和已裁定边界：<路径或摘要；没有则写无>
已核实的当前事实：<附源码和测试依据；未知写未知>
项目地图中的候选模块和文件：<仅作为线索；未命中不代表不存在>

请输出：
1. 可观察的最终结果、当前范围及明确暂缓项。
2. 备选方案、取舍、依赖和需要人类裁定的问题。
3. 会影响方案或验收的源码事实问题，以及可直接执行的工作。
4. 如需拆成多个 Task，为每个 Task 说明独立完成结果和依赖；不要为了形式拆分。
5. 应记录在 Task 中的建议、验证方式、风险和剩余工作。

区分建议、已有决定与当前实现事实；不要假设尚未核对的代码能力已经存在。
```

收到结果后，本地执行者核对相关事实，在 Task 中记录采纳、修改或暂缓的决定和依据。
