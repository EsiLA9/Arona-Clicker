# Task 默认模板

`npm run task -- newTask <slug> "<标题>"` 使用下面的骨架。按 [[ai/guide/task-workflow]] 写正文，完成后删除填写提示。

```markdown
# Task XXXX · 任务名称

状态：待处理

## 1. 任务目标与范围

<!-- 写清面向谁、解决什么问题、交付后能做什么；原型编号用于追踪。 -->

## 2. 当前实现

<!-- 用源码符号、路径和直接调用说明现状及其局限。 -->

## 3. 目标设计

<!-- 写明目标职责、数据和接口，以及正常、失败或交互行为；复杂设计按主题展开。 -->

## 4. 施工方案

<!-- 说明建设顺序、真实调用方如何改接、数据如何迁移、旧职责何时退出。 -->

## 5. 依赖与施工边界

<!-- 说明开工或交付的依赖、可并行工作、保留行为与范围边界。 -->

## 6. 验收标准

<!-- 写真实入口、可观察结果、必要失败场景及迁移或退出的判据。 -->

## 7. 工作项

<!-- 按建设成果或迁移阶段填写复选框。 -->

## 8. 施工记录

待施工。
```
