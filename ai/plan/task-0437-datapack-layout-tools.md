## 文件组织页面

在现有导航中提供单独的「Datapack 文件组织」入口。页面使用现有应用外壳，保留原三栏的表单会话。

1. 顶部显示当前导入来源和操作切换「全拆 / 合一 / 快速层级化」。文件组织使用**本次导入的原始文件内容**。表单有未保存编辑时明确说明这些编辑不参与转换。表单状态保留，之后结合 M04 再支持含草稿的布局操作。
2. 左侧为当前文件树，可展开文件看实体、按文件或声明选择。全包操作显示明确的全量范围。右侧为目标树、未移动项和诊断，可设新目标相对路径。规则、选择和手调复用 0436 计划，更新目标树和诊断，保留来源树选中项和表单状态。
3. 底部提供「取消」与「确认并导出 ZIP 副本」。确认只执行当前输入和参数对应的最新有效预览。更换来源后旧预览失效，重复路径及不完整源可见且禁用确认。可重新导入输出 ZIP，继续分组或选合。浏览器反馈区分作者副本和旧版兼容发行输出。

CLI 复用同一计划和输出判据。预览默认无写入，写入需显式 `--out`。选择、分组、路径覆写或兼容发行输出遇到问题时保留来源路径和诊断。帮助示例使用最终登记的命令。

## 可用交付与验收

在独立工具导入真实目录并改一个表单字段。打开文件组织，验证提示明确且导出的副本仍包含导入时的值，返回表单能继续编辑。再走全拆 → 导入副本 → 按 Init 分组和手调 → 选合，比较 CLI 对同一规则生成的文件与资产。用坏 JSON、路径冲突和更换来源验证禁用或重算预览。通过 `npm test -- tools/datapack-editor/ui/io.test.ts` 及实际命令入口回归，补一次桌面浏览器验收。完成即视为 M01 首批文件组织工具交付。
