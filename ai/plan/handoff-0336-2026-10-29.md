## 已固定的模型 API 与选择器

property-model 的首参是 **draft，不是 state**：

- readProperty / editProperty(draft, nodeId, node-relative path, value)。
- selectNodeType；selectBranch(path, branch)；selectDiscriminant(path, discriminator, branch)。
- toggleOptional / isOptionalEnabled；rowIdAt；addRow / removeRow / moveRow / moveRowBy。
- selectThemeScope、editStage、setNodeStage、missingEnabledOptionalIssues。
- storyDefinitionFromDraft 建议传完整 draft，以包含 editorState；保留旧 document/localFlagInputs 重载。

路径使用 `(string|number)[]`；DOM 可用索引绑定，但缓存/行身份必须稳定。readProperty 读取活动内容，不能让旧分支 rawInputs 覆盖新分支显示。type cache 不缓存公共 requiresFlag；删除行会清理该行及后代缓存。rowIdAt 作为渲染查询不能把纯浏览标记 dirty。

当前表单约定：`data-story-node-type`、`data-story-property-path`、`data-story-branch-path`（配 branch-field）、`data-story-optional-path`、`data-story-row-action/path/id`。path 属性是 JSON 数组。旧 E0 的 data-editor-field/text/sender 和0337 控件选择器需保持已有行为兼容。
