### Constraints

- 三场仍由原有MapRun owner持有；保留完整Map定义与静态Map默认合同。
- `partySetup` 只在首次进入带setup的Node时初始化；重返已访问Node和恢复当前Node都不重新初始化。
- 新增纯 `getMapDefinitionAtNode(definition, nodeId)` 供 owner 与 Runtime ReadModel 解析本场初值/cap/agility；实现由MapRun service导出，Runtime接线由主Agent处理。
- 阶段资源未显式声明时以0开始；资源身份继续从Map Actions导出。新Encounter自然获得新Hand/Prepared、Enemy与局部状态；MapRun statuses在阶段节点首次进入时清空。
- `partySetup` 类型源变更需要主Agent运行 `npm run gen:schema`；本Unit不得编辑生成Schema。
- 遵守 `AGENTS.md` 与架构、测试、Schema同步规范。
