- 每个被测模块对应一个独立 `.test.ts` 文件，文件名与被测源文件同名加 `.test` 后缀，便于一一对应定位。
- 集成测试在 `beforeEach` 中 `new GameInstance()` 并 `game.init([baseDatapack])`，在 `afterEach` 中调用 `game.stop()` 释放资源。
- 通过构造最小化的 JSON 片段（如 INIT_FRAGMENT、AREA_FRAGMENT、SPOT_FRAGMENT）并用 jszip 组装虚拟压缩包，避免依赖外部数据文件。
- UI 测试统一通过 `createUIContext(game)` 创建上下文后再调用渲染函数，断言返回 HTML 字符串中包含特定 class/data 属性而非 DOM 节点。
- 错误路径测试使用 `expect(...).rejects.toThrow(ZipLoadError)` 配合正则匹配中文错误消息（如“未包含任何 Datapack 字段”“顶层是数组”）进行精确断言。
- 长剧情推进采用 while 循环 + guard 计数模式，遇到 `ChoiceRequired` 错误时选择默认选项继续推进，直到 `finished: true`。
