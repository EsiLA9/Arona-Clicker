测试目录按被测模块镜像 src/ 结构组织：`engine/` 下包含大量针对 GameInstance、Story、Spot、Character、Affector、Enhancement、Theme、Roster、Gacha 等子系统单测，以及 `engine/game-instance.test.ts` 作为集成测试入口驱动完整游戏生命周期；`engine/def-factory/` 集中校验 datapack 定义工厂（area/item/story/talklet/trigger 等）；`ui/` 下通过 `createUIContext` 注入真实 GameInstance 来断言渲染输出；`data/` 使用 jszip 构造虚拟压缩包验证 datapack zip 解析。所有测试均直接 import `../../src/**` 源码，不依赖 mock 框架，采用 beforeEach/afterEach 管理 GameInstance 生命周期，并通过 `baseDatapack` 提供最小可运行数据环境。
