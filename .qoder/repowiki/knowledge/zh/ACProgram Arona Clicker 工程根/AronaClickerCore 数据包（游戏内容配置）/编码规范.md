- 每个资源类型独立存放于 `NN-<type>.json` 文件中，文件名以两位数字前缀保证加载顺序。
- 所有资源 ID 统一使用 `base:` 命名空间前缀，跨文件引用通过该 ID 完成。
- 扩展内容通过同类型加 `-millennium` 后缀的文件追加到基础数据之上，实现模块化扩展。
- JSON 中的额外元数据统一封装在 `extra` 字段内，并以 `{ t: 'dict', v: { ... } }` 的结构描述键值对。
- 条件判定统一使用 `{ type: 'AND', conditions: [...] }` 的组合条件格式，比较项包含 target/key/comparator/value。
