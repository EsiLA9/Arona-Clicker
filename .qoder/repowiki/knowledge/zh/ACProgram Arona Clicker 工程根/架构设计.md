根目录通过单一 package.json 暴露 dev/build/test 脚本，由 vite.config.ts 以多入口（portal/game/editor）形式将 src/ui/index.html、tools/datapack-editor/ui/index.html 与 index.html 三个前端产物统一打包到 web-dist；tsconfig.json 启用 strict + ESNext moduleResolution bundler，并排除 tools 目录以避免工具代码参与编译。vitest.config.ts 将 tests/** 与 tools/**/*.test.ts 纳入同一测试套件，使 engine、datapack 编辑器与 UI 组件共享 Node 环境运行。scripts/*.mjs 作为纯 Node 工具被 npm scripts 调用，用于生成 schema 与打包 datapack_assets.zip，从而把数据配置（datapack_assets）与运行时 UI（src/ui）解耦。
