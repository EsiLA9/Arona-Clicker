- 每个脚本通过 `fileURLToPath(import.meta.url)` 计算根目录，再以 `resolve(__dirname, '..')` 定位仓库根，避免硬编码绝对路径。
- 重构类脚本使用集中声明的 `MOVE` 映射表（文件名 → 目标子目录或 `sub:name` 重命名形式）驱动文件移动与 import 重写，便于多阶段脚本共享同一份迁移规则。
- 相对 import 重写采用「先按旧位置解析真实目标、再按新位置计算相对 spec」的双步策略，确保跨目录引用的路径在文件移动后仍然正确。
- CLI 入口统一通过 `process.argv` 检查标志位（如 `--write`、`--dry-run`、`--apply`、`--detail`）切换只读/写入模式，并提供详细 diff 输出。
- schema 生成中对无法自动推导的类型统一归入 `hand` 类别，并通过白名单 `HAND_TYPES`、`EXTRA_TYPES` 与 `ID_REF_TABLE` 显式标注特殊语义。
