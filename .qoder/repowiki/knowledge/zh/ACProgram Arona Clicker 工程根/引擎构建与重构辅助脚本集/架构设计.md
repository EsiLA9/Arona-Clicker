本模块为纯 Node.js ESM 脚本集合，按职责拆分为三类：
- 代码生成：`gen-engine-schema.mjs` 通过 `typescript` 编译器 API 直接解析 `src/engine/types/**/*.ts`，提取接口/类型别名/枚举并基于 `Datapack` 接口的数组与 Record 字段推导 `defMap`，再递归描述各实体字段（string/bool/float/array/record/ref/object/enum/hand），输出 `tools/datapack-editor/schema/engine-defs.gen.json`；其 `.d.mts` 暴露 `parseEngineSchema()` 供 vitest 测试复用。
- 数据打包：`pack-arona-clicker-core.mjs` 递归扫描 `datapack/AronaClickerCore/` 下所有 `.json` 文件并用 `jszip` 压缩为 `arona-clicker-core.zip`。
- 重构修复：`_refactor-move-engine.mjs` 及 `_fix-engine-imports.mjs`、`_fix2-engine-imports.mjs`、`_fix3-engine-imports.mjs`、`_fix-docs-engine-paths.mjs` 构成一组渐进式迁移工具，通过内置的 `MOVE` 映射表将 `src/engine` 顶层文件移动到 core/expression/effect/extra/visibility/system/registry/stats 子目录，并在移动前后分别以旧位置和新位置双重解析相对 import，重写引用路径以保持跨目录引用正确。
依赖方向单向：脚本仅读取仓库源码与 datapack 资源，不引入业务运行时，对外仅通过 CLI 参数（如 `--write`、`--dry-run`、`--apply`）控制行为。
