根目录作为单一 npm 工作区，通过 package.json 的 scripts 将 datapack 数据配置（datapack_assets）、运行时前端（src/ui）、编辑器前端（tools/datapack-editor）、测试套件（tests）与 Node 工具脚本（scripts）串联：vite.config.ts 以 Rollup input 多入口形式把 src/ui/index.html、tools/datapack-editor/ui/index.html 与根 index.html 打包到 web-dist；tsconfig.json 启用 strict + bundler moduleResolution 并排除 tools，使 engine 与 datapack 编辑器共享类型但编译隔离；vitest.config.ts 将 tests/** 与 tools/**/*.test.ts 纳入同一套件，让 engine、datapack zip 加载器与 UI 组件在 Node 环境下共用真实 GameInstance 驱动端到端验证；scripts/*.mjs 由 npm scripts 直接调用，负责生成 datapack editor schema 与打包 datapack_assets.zip，从而把数据配置与运行时 UI 解耦。
