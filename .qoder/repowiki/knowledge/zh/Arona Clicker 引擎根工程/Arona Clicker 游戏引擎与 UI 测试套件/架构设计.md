测试目录镜像 src/ 源码结构组织：`engine/` 下按子系统划分单测（affection-system、character-system、story-flow、spot-*、enhancement-*、theme-*、gacha-service、registry、tick-system 等），并通过 `engine/game-instance.test.ts` 作为集成测试入口，使用完整 GameInstance 生命周期驱动 Story、Spot、Roster、Affector 等子系统协作；`engine/def-factory/` 集中校验 datapack 定义工厂（area/item/story/talklet/trigger/pool-pack 等）对 JSON 片段的解析；`ui/` 下通过 `createUIContext(game)` 注入已初始化的 GameInstance 来断言渲染输出的 HTML 字符串；`data/` 使用 jszip 构造虚拟压缩包，直接调用 `loadDatapackFromZip` / `loadDatapackFromZipBuffer` 验证 datapack 分片合并、图片提取与错误路径。所有测试均直接 import `../../src/**` 源码，不依赖 mock 框架，以 `baseDatapack` 提供最小可运行数据环境。
