根目录作为 Vite + Vitest 多入口工作区的中枢：vite.config.ts 通过 Rollup input 将 index.html（portal）、src/ui/index.html（游戏）与 tools/datapack-editor/ui/index.html（编辑器）打包到 web-dist，并通过自定义 mpaRoutes 插件在 dev/preview 阶段把 /game、/editor 路由映射到对应 HTML；tsconfig.json 启用 strict + bundler moduleResolution，include src/** 与 tests/** 但 exclude tools/**，使 engine 与 datapack 编辑器共享类型定义但编译隔离；vitest.config.ts 将 tests/** 与 tools/**/*.test.ts 纳入同一套件，让 engine、datapack zip 加载器与 UI 组件在 Node 环境下共用真实 GameInstance 驱动端到端验证；scripts/*.mjs 由 npm scripts 直接调用，负责生成 datapack editor schema 与打包 datapack_assets.zip，从而把数据配置（datapack_assets）与运行时 UI（src/ui）、编辑器（tools/datapack-editor）解耦。
