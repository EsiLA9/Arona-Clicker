模块采用按资源类型分片的纯数据配置结构：每个 `NN-<type>.json` 文件对应一种实体类型（pics/inits/areas/spots/enhancements/stories/items/droptables/affector-packs/triggers/characters/extras），文件名以两位数字前缀保证运行时按顺序依次加载合并；同一类型的扩展内容通过 `-millennium` 后缀文件追加到同名基础文件中，形成“基础 + 扩展”的叠加式数据模型。根目录提供两个 zip 归档 `arona-clicker-core.zip` 与 `arona-clicker-core2.zip` 作为最终交付给游戏引擎的数据包产物。所有资源 ID 统一使用 `base:` 命名空间前缀，跨文件引用通过该 ID 完成（如 enhancement 的 `attachment.initId` 引用 init、trigger 的 effects 引用 item）。JSON 中的额外元数据统一封装在 `extra` 字段内，并以 `{ t: 'dict', v: { ... } }` 的结构描述键值对。
