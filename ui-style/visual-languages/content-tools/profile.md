# 内容检索工具视觉语言

**已采用。** 适用超级图鉴和 Runtime 内容浏览器。高密度分类和检索置于导航与条目区，详细资料或编辑表单占独立区域。列表保留对象名称与来源，长引用、字段树和技术诊断放在详情层。只读图鉴优先显示资料和引用，Draft 浏览器保留待应用状态及固定提交动作。

- **已观察。** body 级 Runtime Editor 浮动宿主接入两处界面。图鉴及内容浏览区域消费 `--codex-*` 的局部表面、文字、边框和强调角色，外层及编辑表单还使用 `--re-*`。从工具自身的角色和控件继承，局部色值适用该工具范围。依据为 `src/ui/runtime-editor/codex/codex.css`、`src/ui/css/runtime-editor.css`、`src/ui/runtime-editor/view.ts`。
- 游戏内收藏图鉴采用游戏弹窗及卡片网格，见 [[ui-style/visual-languages/game-ui/patterns|游戏模式]]。独立 Datapack Editor 使用自己的 HTML 与样式入口，见 [[ui-style/00-index|视觉语言索引]]。
